# 博客系统

使用 Markdown 在净读撰写和发布博客文章，分享你的想法。

## 浏览博客

- 在首页作品广场点击 **博客** 标签，或访问 `/?type=blog`
- 博客列表进入统一无限瀑布流，滚动加载下一页；旧的 `/blog` 入口仍然可用
- 博客内容使用 Markdown 渲染，支持代码高亮和目录导航

## 发布博客

1. 登录后，在 `/publish` 选择 **博客** 标签（也可以直接访问 `/blog/create`）
2. 输入：
   - **标题** — 博客标题
   - **内容** — 支持 Markdown 格式；使用工具栏、分栏预览、站内内容/播放器插入与投票管理
3. 点击「发布」

::: info 发布限制
- 每天最多发布 **2 + 等级** 篇博客（如 Lv.3 用户每日上限 5 篇）
- 单篇博客内容字数上限：**50000字**
- 发布博客可获得 **10 经验值**，每日最多 10 次
:::

## 博客编辑器

发布页与编辑页使用同一套 Markdown 编辑器：

- 工具栏：加粗、斜体、删除线、行内代码、标题、引用、列表、代码块、链接、表格、分隔线、配图。
- 桌面端左侧编写、右侧实时预览；移动端在「编写 / 预览」之间切换，也可以全屏编辑。
- 支持 Ctrl / Cmd + B、I、K 与 Tab / Shift + Tab 缩进。
- 输入过程中会把草稿保存在**本机浏览器**（localStorage），下次打开同一篇博客时可以恢复或丢弃；草稿不会上传服务器，也不会跨设备同步。
- 无 JavaScript 时仍可正常输入 Markdown 并提交，只是没有工具栏与实时预览。

## 嵌入站内内容与播放器

正文中可以使用独占一行的令牌插入站内内容卡片或播放器。编辑器提供「站内内容」「播放器」按钮，不需要手写令牌。

| 内容 | 令牌 |
| --- | --- |
| 帖子 | `[[embed:forum:123]]` |
| 博客 | `[[embed:blog:123]]` |
| 工程 | `[[embed:project:123]]` |
| 资源 | `[[embed:resource:123]]` |
| 小说 | `[[embed:novel:<book_id>]]` |
| 网易云单曲 | `[[player:netease:song:123456]]` |
| 网易云歌单 | `[[player:netease:playlist:123456]]` |
| 哔哩哔哩视频 | `[[player:bilibili:BV1xx411c7mD]]` |

规则与限制：

- 卡片只读取**公开内容**：工程必须已通过审核，小说必须有公开正文；内容被删除、下架或审核中时显示「内容不可用」，不会泄露标题与作者。
- 网易云与哔哩哔哩播放器采用**点击后加载**：页面打开时不会向第三方发请求；点击播放后才创建官方 iframe，可能使用第三方 Cookie。播放器下方始终保留「在第三方打开」的链接。
- 只接受网易云歌曲/歌单 ID 与 B 站 BV / av 号（可带分 P），不接受任意 URL 或自定义 iframe。
- 令牌必须独占一行；放进代码块或段落中间的令牌会按普通文本处理，避免生成非法 HTML。
- 每篇博客最多 **30 个**卡片/播放器/投票令牌，超出部分不会展示。
- 站内卡片与播放器令牌会从列表摘要、搜索摘要中剥离，不会出现在作品卡片上。

## 投票

编辑器可以给博客添加投票：

- 每篇博客最多 **3 个**投票，每个投票 **2 至 10 个**选项，问题最多 100 字，选项最多 50 字。
- 支持单选或多选，可设置截止时间；作者可以提前结束投票。
- 登录后才能投票，每个账号每个投票一份 ballot，截止前可以改票；投票后可见结果，截止后所有人可见，作者始终可见。
- 有人投票后不能修改选项或切换单选/多选，但可以修改问题与截止时间；从正文移除投票令牌后不再展示，已有投票记录保留用于审计。
- 投票问题与选项会和正文一起经过敏感词过滤与 AI 审核。
- 未启用 JavaScript 时，投票表单仍可提交并回到博客详情页。

## 分区与标签

- 发布博客时需要选择分区：**杂谈、教程、心得、评测、资讯**；未选择或参数异常时自动归入 **杂谈**。
- 可以填写最多 **5 个**标签，每个标签不超过 **10 个字符**，用逗号分隔；不填时显示「无标签」。
- 分区与标签会显示在作品流卡片和博客详情中。点击卡片上的分区或标签，可以只看该分区 / 标签下的内容。
- 编辑博客时可以同时修改分区与标签。

::: tip 发布前审核
博客发布与编辑会先经过发布频率、重复与广告等算法风控，再走 AI 内容审核：通过即刻发布；提示未通过时可修改后重新提交；少数内容会转人工复核，复核通过后自动发布，可在 **我的作品**（`/my/works`）看到「审核中 / 未通过」状态。评论命中广告、联系方式、灌水等风险时也会送 AI 审核。详见 [内容审核与风控](/features/moderation)。
:::

## 博客配图

- 发布或编辑博客时，可以选择最多 **9 张**配图，支持 JPG / PNG / WebP，单张不超过 **5 MB**。
- 图片上传时先校验扩展名、大小与文件头，再送**视觉模型 AI 审核**；明确通过后才写入公开存储并分发。
- 已发布博客的配图会显示在作品广场卡片与博客详情页；删除博客时会一并清理配图记录与已上传的图片文件。
- 配图可以**插入正文**：选择图片后点击预览图上的「插入正文」，会在光标处写入 `jingdu-image:<图片ID>` 令牌，发布后渲染为文中图片；没有被正文引用的图片才显示在文章底部。
- 博客详情页的配图点开即可**在页内放大**（不再跳转图片地址）：多图可左右切换，键盘 ← → 翻页、Esc 关闭，手机上可左右滑动；Ctrl / Cmd + 点击仍按浏览器默认行为在新标签打开原图。
- 编辑博客时可以勾选删除已有配图，也可以继续添加新图；保留的旧图不会重复审核，新增图片仍会先经过视觉模型审核。配图总数最多 9 张。

## 正文内嵌配图

- 编辑页会列出已有配图，每张图下方有「插入第 N 张到正文」按钮；新选择的图片在预览图底部有「插入正文」按钮。
- 文中图片和底部配图都支持页内放大；修改正文或删除配图前，请先移除文中对该图的引用，否则保存会被拒绝。
- 新增图片仍先经过视觉模型审核；正文中的令牌只引用当前博客自己的图片，不能跨博客引用。

## 博客详情

点击博客标题进入详情页，可以查看：

- 博客完整内容（Markdown 渲染为 HTML，含站内内容卡片、播放器与投票）
- 评论区
- 作者信息

## 评论博客

1. 在博客详情页底部的评论区输入你的评论
2. 点击「发表评论」

::: tip
- 登录后评论可获得 **3 经验值**，每日最多 10 次
- 评论会显示 IP 归属地
:::

## 管理博客

### 我的博客

登录后，通过博客页面的 **我的博客** 入口查看你发布的所有博客。

### 编辑博客

- 进入博客详情页，点击 **编辑** 按钮（仅作者可见）
- 修改标题、内容、分区与标签；也可以勾选删除已有配图、选择新图补充
- 点击「保存」后，正文、分区、标签与配图一起生效；新增图片未通过 AI 审核时不会保存

### 删除博客

- 进入博客详情页，点击 **删除** 按钮（仅作者可见）

### 删除评论

- 博客作者和评论者可以删除评论


## 点赞与点踩

博客文章支持 **点赞** 与 **点踩**，用于表达对文章的真实看法：

- **点赞**：文章作者获得 `+2` 净币
- **点踩**：文章作者扣除 `1` 净币（作者净币余额可能因此变为负数）
- **同一篇文章只能点赞或点踩**：再次点击同一种态度即为取消；从点赞改为点踩时，会先回退点赞收益再结算点踩
- **取消会对称回退**：取消点赞扣回 2 净币，取消点踩返还 1 净币，反复切换不会凭空产生净币
- **给自己的文章点赞或点踩只记录态度**，不结算净币

为防止多账号恶意刷负，每个作者每日因被点踩而扣除的净币有上限（默认 20 净币）；达到上限后仍可被点踩并正常计数，但当天不再继续扣减。

### 收藏、转发与评论

- 博客与帖子、资源共用统一的点赞 / 点踩 / 收藏 / 转发 / 评论操作；收藏和点赞可在「我的收藏 / 我的点赞」跨类型查看。
- 评论支持楼中楼回复，作者或内容作者可以删除评论；删除父评论会一并删除其回复。
- 转发通过私信发送站内内容卡片，卡片展示博客标题、作者、摘要和真实互动数。

详见 [净币系统](/features/coin#互动与净币)。
