# 博客系统

使用 Markdown 在净读撰写和发布博客文章，分享你的想法。

## 浏览博客

- 在首页作品广场点击 **博客** 标签，或访问 `/?type=blog`
- 博客列表进入统一无限瀑布流，滚动加载下一页；旧的 `/blog` 入口仍然可用
- 博客内容使用 Markdown 渲染，支持代码高亮和目录导航

## 发布博客

1. 登录后，在 `/publish` 选择 **博客** 标签（也可以直接访问 `/blog/create`）
2. 输入：
   - **标题** — 博客标题
   - **内容** — 支持 Markdown 格式
3. 点击「发布」

::: info 发布限制
- 每天最多发布 **2 + 等级** 篇博客（如 Lv.3 用户每日上限 5 篇）
- 单篇博客内容字数上限：**50000字**
- 发布博客可获得 **10 经验值**，每日最多 10 次
:::

## 分区与标签

- 发布博客时需要选择分区：**杂谈、教程、心得、评测、资讯**；未选择或参数异常时自动归入 **杂谈**。
- 可以填写最多 **5 个**标签，每个标签不超过 **10 个字符**，用逗号分隔；不填时显示「无标签」。
- 分区与标签会显示在作品流卡片和博客详情中。点击卡片上的分区或标签，可以只看该分区 / 标签下的内容。
- 编辑博客时可以同时修改分区与标签。

::: tip 发布前审核
博客发布与编辑会先经过发布频率、重复与广告等算法风控，再走 AI 内容审核：通过即刻发布；提示未通过时可修改后重新提交；少数内容会转人工复核，复核通过后自动发布，可在 **我的作品**（`/my/works`）看到「审核中 / 未通过」状态。评论命中广告、联系方式、灌水等风险时也会送 AI 审核。详见 [内容审核与风控](/features/moderation)。
:::

## 博客配图

- 发布或编辑博客时，可以选择最多 **9 张**配图，支持 JPG / PNG / WebP，单张不超过 **5 MB**。
- 图片在服务端校验扩展名、大小与文件头后，会先送**视觉模型 AI 审核**；明确通过才写入公开 OSS 桶（`jingdu-proj-public`，经 `cdn.jingdu.org` 分发）。
- 已发布博客的配图会显示在作品广场卡片与博客详情页；删除博客时会一并清理配图记录与 OSS 对象。
- 博客详情页的配图点开即可**在页内放大**（不再跳转图片地址）：多图可左右切换，键盘 ← → 翻页、Esc 关闭，手机上可左右滑动；Ctrl / Cmd + 点击仍按浏览器默认行为在新标签打开原图。
- 编辑博客时可以勾选删除已有配图，也可以继续添加新图；保留的旧图不会重复审核，新增图片仍会先经过视觉模型审核。配图总数最多 9 张。

## 博客详情

点击博客标题进入详情页，可以查看：

- 博客完整内容（Markdown 渲染为 HTML）
- 评论区
- 作者信息

## 评论博客

1. 在博客详情页底部的评论区输入你的评论
2. 点击「发表评论」

::: tip
- 登录后评论可获得 **3 经验值**，每日最多 10 次
- 评论会显示 IP 归属地
:::

## 管理博客

### 我的博客

登录后，通过博客页面的 **我的博客** 入口查看你发布的所有博客。

### 编辑博客

- 进入博客详情页，点击 **编辑** 按钮（仅作者可见）
- 修改标题、内容、分区与标签；也可以勾选删除已有配图、选择新图补充
- 点击「保存」后，正文、分区、标签与配图一起生效；新增图片未通过 AI 审核时不会保存

### 删除博客

- 进入博客详情页，点击 **删除** 按钮（仅作者可见）

### 删除评论

- 博客作者和评论者可以删除评论


## 点赞与点踩

博客文章支持 **点赞** 与 **点踩**，用于表达对文章的真实看法：

- **点赞**：文章作者获得 `+2` 净币
- **点踩**：文章作者扣除 `1` 净币（作者净币余额可能因此变为负数）
- **同一篇文章只能点赞或点踩**：再次点击同一种态度即为取消；从点赞改为点踩时，会先回退点赞收益再结算点踩
- **取消会对称回退**：取消点赞扣回 2 净币，取消点踩返还 1 净币，反复切换不会凭空产生净币
- **给自己的文章点赞或点踩只记录态度**，不结算净币

为防止多账号恶意刷负，每个作者每日因被点踩而扣除的净币有上限（默认 20 净币）；达到上限后仍可被点踩并正常计数，但当天不再继续扣减。

详见 [净币系统](/features/coin#互动与净币)。
