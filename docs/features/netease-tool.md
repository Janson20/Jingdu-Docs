# 网易云搜索 · 试听 · 歌词

给 P 主找参考曲用的站内工具，页面在 `/netease`。

## 一、能做什么

- 按歌名 / 歌手 / 关键词搜索网易云曲库（20 条一页）
- 点击试听：页面里直接嵌入**网易云官方播放器**，点播放即可
- 下载 LRC：拉取歌词原文，自动下载为 `.lrc`；也可先预览或复制全文
- 复制歌曲链接（`https://music.163.com/#/song?id=…`）
- 搜索历史存在浏览器 `localStorage`，**不上传**

## 二、为什么搜索走服务端

网易云官方接口（`music.163.com/api/*`）**不返回 `Access-Control-Allow-Origin`**，
也不支持 JSONP，浏览器 `fetch` 读不到响应体。因此搜索与歌词由服务端请求网易云，
浏览器只和自己的站点通信——没有 CORS 问题，也不依赖第三方聚合接口。

代价是请求量落在本站，所以**每个端点都限频**（按 IP）：

| 端点 | 限制 |
| --- | --- |
| `GET /netease/api/search?q=` | 20 次/分钟，400 次/天 |
| `GET /netease/api/lyric?id=` | 30 次/分钟，600 次/天 |

超限返回 `429`，前端提示「请求太频繁了，歇一会儿再试」。

> 限频由 Flask-Limiter 的内存存储实现，**每个 worker 单独计数**：
> `gunicorn -w 4` 时实际额度约为标注值的 4 倍。要精确限制需把存储换成 Redis
> （项目已支持 Redis 缓存，配好即可）。

## 三、试听为什么用 iframe

试听不解析音频直链，而是嵌入官方外链播放器：

```
https://music.163.com/outchain/player?type=2&id=<歌曲ID>&auto=0&height=66
```

好处：

- **音频完全不经过本站**，既不代理流也不解析地址，带宽与版权风险都归零；
- 会员 / 版权受限的曲目，能不能听、能听多少由网易云自己判定，本站不必猜；
- 少一个服务端接口（原 `/netease/api/url` 已删除）和一次 302 解析。

`auto=0`：不自动播放。跨域 iframe 的自动播放大概率会被浏览器策略拦掉，
让用户点播放键更稳。

CSP 必须放行 `frame-src https://music.163.com`，否则 iframe 会被静默拦掉，
页面上只剩一块空白。页面已不需要 `media-src` 里的网易云 CDN 源——音频在
iframe 内部加载，与外层文档的 CSP 无关。

## 四、上游调用与缓存

`netease_api.py` 封装两个官方接口：

| 用途 | 上游 | 返回处理 |
| --- | --- | --- |
| 搜索 | `/api/search/get` | 精简为 `{id, name, artists[], album, duration}` |
| 歌词 | `/api/song/lyric` | 取 `lrc.lyric` 与 `tlyric.lyric` |

缓存（进程内内存，非内容库）：搜索 2 分钟、歌词 30 分钟，上限 512 条，超出淘汰一半。

## 五、错误处理

- 上游超时/异常 → `502` + 「连接网易云失败，请稍后重试」
- 无歌词 → `404` + 「这首歌没有公开歌词」
- 参数非法 → `400`
- 超限 → `429`

## 六、边界与风险

- 播放器是第三方内容，界面与本站在视觉上不一致，属于预期。
- 会员曲目在未登录网易云的浏览器里可能只给试听片段，这是对方的策略。
- 歌词版权归原作者与版权方，下载仅建议用于学习、字幕、PV 等场景，不要二次分发。
- 服务端会看到搜索关键词，但**不落库、不写日志**；限频只按 IP 计数。
- 换上游或调整限频时，记得同步 `config.NETEASE_TOOL["limits"]`（页面展示用）
  与 `routes/netease.py` 的装饰器。
