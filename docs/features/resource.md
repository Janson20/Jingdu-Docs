# 资源分享

分享有用的软件资源，支持标签、版本管理和网盘链接。

## 浏览资源

- 在首页作品广场点击 **资源** 标签，或访问 `/?type=resource`
- 资源进入统一无限瀑布流，每张卡片展示资源名称、版本、作者、**标签**、简介和浏览量
- 卡片上的标签可以直接点击，继续按该标签筛选
- 顶部搜索框支持关键词与标签组合检索；旧的 `/resource/` 入口仍然可用

## 资源详情

点击资源进入详情页，查看：

- **名称** — 资源名称
- **版本** — 当前版本号
- **作者** — 资源上传者
- **标签** — 资源标签，点击标签可查看同标签的其他资源
- **简介** — 资源说明
- **官网** — 官方网站链接
- **网盘链接** — 下载地址
- **提取码** — 网盘提取码
- **版本历史** — 所有历史版本记录

::: tip 发布审核
资源名称、简介与链接会经过发布频率、重复与广告等算法风控，再走 AI 审核；需要人工复核时不会立即发布。网盘链接属于正常内容，不会因为链接多而误判。
:::

## 发布资源

1. 登录后，点击资源页面的 **新建资源** 按钮
2. 填写以下信息：
   - **资源名称**
   - **版本号**
   - **作者**
   - **简介**
   - **标签**（可选，详见下方 [资源标签](#资源标签)）
   - **官网地址**
   - **网盘链接**
   - **网盘提取码**
3. 点击「发布」

## 资源标签

发布或编辑资源时可以填写标签，方便他人按用途、平台、类型等维度查找：

| 规则 | 说明 |
|------|------|
| 单个标签长度 | 最长 **10 个字符**（中文按 1 个字符计算） |
| 标签数量 | 每个资源最多 **5 个** |
| 重复标签 | 自动去重（忽略大小写），只保留一个 |
| 空标签 | 自动丢弃，不会保存 |
| 超限处理 | 标签过长或数量超限时会直接提示，不会静默截断 |
| 无标签资源 | 未填写任何标签时，系统自动归入「**无标签**」，该标签不会与其他标签同时出现 |

填写方式：在标签输入框中输入内容后按回车（或逗号）即可添加，点击标签上的 × 可移除。

- **点击标签筛选** — 资源列表、资源详情、我的资源、搜索结果中的标签都可以点击，跳转到 `/resource/search?tag=<标签名>` 查看同标签资源
- **标签直达链接** — `/resource/tag/<标签名>` 会自动跳转到该标签的筛选页，方便直接分享
- **敏感词过滤** — 标签与资源名称、简介一样会经过敏感词过滤
- **历史资源** — 升级前已发布、原本没有标签的资源，会自动归入「无标签」

## 管理资源

### 我的资源

登录后，通过个人中心的 **我的作品**（或 `/my/works?type=resource`）查看你发布的所有资源，列表中会展示每个资源的标签。

### 编辑资源

- 进入资源详情页，点击 **编辑** 按钮（仅所有者可见）
- 可以随时修改标签：删除全部标签保存后，资源会重新归入「无标签」
- 修改信息后可以选择 **保存为新版本**，自动生成版本历史
- 也可以直接覆盖当前版本

### 删除资源

- 进入资源详情页，点击 **删除** 按钮（仅所有者可见）

## 搜索资源

在资源首页的搜索框中输入关键词，即可搜索匹配的资源：

- 关键词会同时匹配 **资源名称 / 作者 / 简介 / 标签**
- 搜索结果页也会展示标签筛选栏，可继续按标签缩小范围
- 搜索与标签可以叠加，例如同时按关键词和「工具」标签筛选
- 搜索结果分页展示，翻页时会保留当前的搜索词和标签条件


## 下载与分享奖励

资源详情页的「获取资源」按钮会先经过站内下载入口（`/resource/download/<id>`）记录下载行为，再跳转到你填写的网盘链接：

- 其他用户**首次**通过站内入口获取你分享的资源时，你获得 `+5` 净币
- 同一个用户对同一个资源只结算一次
- 分享者自己下载不结算
- 历史版本的下载按钮同样经过站内记录，但不重复结算奖励
- 未登录用户也能正常获取链接，只是不参与奖励结算

详情页会显示该资源已有多少位用户通过站内入口获取过，以及其中多少次已为分享者结算奖励。
