# 净读日报

每天 17:00，「净读日报」官方账号会发布一篇日报，帮你快速了解当天值得关注的歌声合成动态（国内、国外分开），以及国内国际新闻。

## 日报里有什么

日报使用固定的版式，每天打开都能按同样的顺序阅读：

- **导语**：一句话点出当天最值得读的事；
- **今日要览**：四个板块各一条，先扫一眼就知道当天值不值得细读；
- **歌声合成（国内）**：中国大陆及港澳台的声库、引擎、制作人与作品动态；
- **歌声合成（国外）**：其他国家和地区的声库、引擎、制作人与作品动态；
- **国内新闻**：当天值得关注的国内大事；
- **国际新闻**：当天值得关注的国际事件；
- **每日一曲**：从本周「周刊虚拟歌手中文曲排行榜」随机抽取一首歌，附上推荐理由和哔哩哔哩播放器。

每条新闻是一个小标题加一段正文，板块之间用一条分隔线隔开；正文不列来源编号、来源列表或网址，方便直接阅读。

歌声合成板块只收录传统歌声合成引擎（VOCALOID、Synthesizer V、UTAU、CeVIO、ACE Studio 等）的声库、引擎与用它们制作的作品；虚拟主播（VTuber）和真人运营的虚拟偶像的直播、日常、商业活动与演唱会不写入日报。

## 只写今天的新闻

日报只收录**北京时间当天**发生或当天发布的新闻。昨天及更早的旧闻、时间线回顾不会写进来；如果当天某个板块没有可靠新闻，日报会明确写「今日暂无可靠更新」，而不是拿旧闻凑数。

因为只写当天，日报的篇幅会随当天新闻量变化：新闻多的时候条目多一些，新闻少的时候可能只有一两条。每天 17:00 发布，也是为了尽量覆盖当天的信息。

## 每日一曲

「每日一曲」由系统从本周「周刊虚拟歌手中文曲排行榜」的榜单中随机抽取，不需要你选择。播放器使用哔哩哔哩官方外链，只有点击后才会加载，不会在打开日报时自动向第三方发请求。

## 什么时候可能没有日报

日报依赖公开新闻来源、自动编辑流程与榜单数据。遇到数据源故障、资料不足或编辑校验不通过时，当天可能不会发布，而不是用旧闻、编造内容或缺失板块来凑一篇。系统会自动重试；仍未成功时，等下一次 17:00。

日报是自动生成的编辑摘要，不替代原始报道；重要信息请以原始来源为准。如果你发现事实错误、过时信息或格式问题，欢迎通过[反馈中心](https://jingdu.productbridge.io)或站内反馈渠道告诉我们。
