# 账号封禁

净读对严重或反复违反[社区规范](https://jingdu.org/community)的账号保留暂停使用的权利。封禁针对的是**账号的使用权限**，不会删除你已发布的内容。

::: tip 一句话说明
被封禁的账号会立即被踢下线，无法进入站内或调用站内 API；封禁时会向绑定邮箱发送通知。你可以登录后提交申诉，临时封禁到期后自动恢复，永久封禁需要管理员复核解除。
:::

## 什么情况会被封禁

封禁属于较重的处理手段，通常用于以下情形：

- 发布违法违规、危害未成年人或侵犯他人权利的内容
- 恶意刷分、刷票、批量注册、使用自动化脚本操纵榜单或收益
- 反复发布广告、诈骗、恶意链接，或多次警告后仍不改正
- 恶意举报、骚扰其他用户，情节严重
- 其他严重违反[用户协议](https://jingdu.org/user-agreement)与[社区规范](https://jingdu.org/community)的行为

一般的审核未通过、单次轻微违规不会直接封禁，以提示修改或限制单次发布为主。

## 封禁后会发生什么

| 项目 | 封禁期间的表现 |
|---|---|
| 已登录的浏览器 | 下一次打开页面时立即退出登录，跳转到封禁说明页 |
| 重新登录 | 密码（及 2FA）验证通过后进入申诉页，不进入站内 |
| API / 第三方客户端 | 已签发的登录 Token 全部失效，接口返回 403 |
| 已发布的内容 | **保留**，不会被自动删除或隐藏 |
| 净币、积分、书架 | 保留在账号内，解封后继续可用 |

封禁说明页会写明**封禁原因**、**封禁时长**与你被封禁的时间。如果是限时封禁，页面会显示具体的解封时间。

## 限时封禁与永久封禁

- **限时封禁**：管理员按天设置（例如 7 天、30 天），到期后系统自动解除，无需人工操作。
- **永久封禁**：没有解封时间，需要管理员在管理面板手动解除。

限时封禁到期后，直接重新登录即可；如果页面仍显示封禁，通常只是浏览器缓存了旧页面，刷新一次即可。

## 封禁通知邮件

封禁生效后，系统会向账号绑定的邮箱发送一封通知邮件，说明访问权限已被撤销，并告知可以通过该账号登录提交申诉。

邮件只发送到账号已绑定的邮箱。没有绑定邮箱的账号不会收到邮件，但仍然可以使用密码登录申诉；管理端会明确显示「账号未绑定邮箱，通知邮件未发送」。

## 如何申诉

1. 使用被封禁的账号进入[登录页](https://jingdu.org/login)，输入用户名和密码。
2. 如果账号开启了 2FA，先完成 2FA。
3. 登录成功后不会进入站内，而是被引导到**申诉页**；页面会写明封禁原因、封禁时间与解封时间。
4. 填写申诉说明（20–1000 字），提交后等待管理员处理。

申诉规则：

- 同一封禁最多提交 **2 次**申诉
- 有申诉正在处理时不能重复提交
- 申诉被驳回后，需间隔 **24 小时**才能再次提交
- 申诉不会自动解封；管理员复核通过后会立即解封，并通过邮件通知结果

处理结果会发送到账号绑定邮箱，也可以在申诉页查看每次申诉的状态与管理员说明。封禁记录会保留操作时间、原因与操作管理员，便于复核。

如果你无法登录账号提交申诉，可以通过[反馈中心](https://jingdu.productbridge.io)联系我们，并附上用户名、封禁原因与时间。


## 常见问题

**Q：封禁会删除我的书或帖子吗？**
A：不会。封禁只暂停账号的使用权限，内容保持原样。

**Q：封禁期间能用别的账号吗？**
A：可以正常注册和使用其他账号，但通过多账号规避封禁属于违规行为，可能导致关联账号一并处理。

**Q：解封后我的数据还在吗？**
A：在。净币、AI 积分、书架、作品与阅读进度都不会因为封禁而清空。

**Q：登录后被带到申诉页，是正常的吗？**
A：正常。被封禁的账号不会进入站内，密码（及 2FA）验证通过后会直接进入申诉页，页面会显示封禁原因与解封时间。

**Q：没有收到封禁邮件怎么办？**
A：请先确认账号是否绑定了邮箱，并检查垃圾邮件目录。未绑定邮箱的账号不会收到通知，但仍然可以登录申诉；如果邮箱已绑定却长时间未收到，可以通过反馈中心联系我们。

**Q：申诉被驳回后还能再申诉吗？**
A：同一封禁最多可以提交 2 次申诉。被驳回后需要间隔 24 小时才能再次提交；超过次数后请通过反馈中心联系。

**Q：申诉通过后需要做什么？**
A：重新登录即可。解封后原登录 Token 不会恢复，系统会发送一封通过通知邮件。
