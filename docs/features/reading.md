# 书籍阅读

## 浏览书籍

### 首页推荐

首页展示以下内容，无需登录即可浏览：

- **热门推荐** — 4 本热门书籍
- **最新上传** — 8 本最新上传的书籍
- **最新更新** — 4 本最近更新的书籍
- **书籍标签** — 所有可用的书籍标签，点击可按标签浏览
- **公告** — 网站最新公告
- **一言** — 随机展示一句话

### 图书库

点击导航栏 **图书库** 进入书籍列表页面：

- 书籍以卡片形式展示（封面、标题、作者、标签、评价统计）
- 支持分页浏览（每页 32 本）
- 使用底部页码进行翻页
- 顶部搜索框支持按关键词搜索（书名 / 作者 / 简介 / 标签）
- 搜索框下方的标签栏可一键筛选同标签书籍

### 标签浏览

- 在首页或图书库点击任意标签，可按标签浏览书籍
- URL 格式：`/search/<标签名>`
- 图书库也支持直接筛选：`/book?tag=<标签名>`

> 说明：书籍原本的「分类」已升级为**多标签**，历史分类数据会自动迁移为书籍的第一个标签。

### 搜索书籍

在 **图书库** 顶部的搜索框输入关键词即可搜索，支持匹配 **书名 / 作者 / 简介 / 标签**：

- 书库内搜索：`/book?q=<关键词>`
- 独立搜索页：`/search?q=<关键词>`
- 搜索关键词与标签筛选可以叠加使用（如 `/book?q=少年&tag=玄幻`）
- 搜索结果中的标签同样可以点击，继续按标签筛选

## 书籍详情

点击书籍卡片进入 **书籍详情页**，可以查看：

- **封面图片** — 书籍封面
- **书名** — 书籍标题
- **作者** — 点击作者名可查看该作者的所有作品
- **标签** — 书籍标签（最多 5 个，每个不超过 10 个字符），点击标签可浏览同标签书籍；作者本人可在本页点击「修改标签」自助修改
- **简介** — 作者撰写的书籍描述
- **评价统计** — 推荐/不推荐的评价概况（详见 [书籍评价](/features/review)）
- **目录** — 所有章节列表，点击章节标题开始阅读
- **催更按钮** — 点击进入书末页的催更位置（详见 [催更功能](/features/urge)）
- **AI 整本概括** — 一键将全书所有章节发送至 AI 聊天，请求对整本书进行概括分析

### AI 整本概括

在书籍详情页的操作按钮区域，有一个 **🤖 整本概括** 按钮：

1. 点击按钮，弹出确认窗口
2. 窗口会显示书籍名称、章节总数，并提醒"概括可能消耗较多积分"
3. 确认后，系统自动拼接全部章节内容为文本文件
4. 跳转到 AI 聊天页面，AI 自动对整本书进行全面概括

::: warning
整本概括需要处理全书所有章节，消耗的积分较多且耗时更长。建议在积分充裕时使用。
:::

## 阅读页面

阅读页面提供：

- **章节内容** — 纯文本展示
- **上一章/下一章** — 章节间快速切换；读到最后一章时，点击 **下一章** 会进入 **书末页**
- **返回目录** — 回到书籍详情页
- **目录跳转** — 点击返回目录后可选择其他章节
- **AI 概括本章** — 页面右侧浮动按钮，一键将当前章节发送至 AI 聊天并请求概括

::: tip
章节不存在时（例如手改网址、章号越界、章节文件缺失）会直接显示「章节不存在」错误页，不会再显示一章空白占位内容。
:::

### 书末页

读到本书最后一章后点击 **下一章**，会进入 **书末页**（`/read/<book_id>/end`）。书末页提供：

- **读完提示** — 显示「已读完」以及本书总章数
- **书籍信息** — 封面、书名、作者、标签与简介
- **催更按钮** — 一键为本书催更，按钮上直接显示本书的累计催更次数（详见 [催更功能](/features/urge)）
- **快捷入口** — 返回目录、从头再看、加入书架、去书库逛逛

### AI 概括本章

在阅读页面右侧，有一个紫色的 **🤖 概括** 浮动按钮：

1. 点击按钮，系统自动将当前章节内容拼接为文本文件
2. 自动跳转到 AI 聊天页面，附上章节文件
3. AI 自动发送概括指令，从核心情节、人物关系变化、关键事件与转折点三个方面概括本章

::: tip
使用 AI 概括功能需要登录并开通 AI 服务。概括会消耗 AI 积分，详见 [AI 聊天计费规则](/features/ai-chat#积分系统)。
:::

### 段评（段落评论）

阅读时可为任意段落发表评论，与同好交流阅读感想：

- **发表段评** — 电脑端把鼠标移到段落上，点击段落末尾的气泡按钮即可评论；手机端段落末尾的气泡按钮常驻显示，直接点击即可。内容限 **300 字**以内。
- **查看段评** — 点击气泡按钮打开段评面板，按段落展示该段的所有评论与回复，未登录也可浏览。
- **点赞与排序** — 可点赞或取消点赞；有评论的段落气泡以主题色显示评论总数（含楼中楼），排序时热门评论靠前。
- **回复（楼中楼）** — 支持回复具体某条评论，最多两层（顶层 + 回复）；回复别人的回复时会自动提及对方（@用户名）。
- **作者徽章** — 书籍作者在本书发表段评时会显示特殊「作者」徽章。
- **删除** — 可以删除自己的段评；书籍作者可删除本书任意段评，删除顶层评论会连及其全部回复。
- **评论标记** — 有段评的段落左侧会显示主题色竖线标记，方便快速定位。

::: tip
发布段评可以获得 **3 经验值**，每日最多 20 次；段评被点赞，作者获得 **1 经验值**，每日最多 30 次。段评内容受 [社区规范](/community) 约束。
:::

### 阅读设置

在阅读页面，点击右侧的 **⚙ 设置按钮** 或按键盘 `S` 键打开阅读设置面板，可以自定义以下选项：

| 设置项 | 选项 | 说明 |
|--------|------|------|
| 字号 | 小 / 中 / 大 / 超大 | 调整正文字体大小 |
| 行间距 | 紧凑(1.5) / 标准(1.8) / 宽松(2.0) / 极宽(2.5) | 调整正文行间距 |
| 字体 | 默认 / 宋体 / 黑体 | 切换正文字体 |
| 背景色 | 白色 / 护眼绿 / 羊皮纸 / 夜间 | 切换阅读背景主题 |

**快捷键列表：**
- `←` 上一章 · `→` 下一章
- `S` 打开/关闭设置面板 · `T` 回顶部
- `Esc` 关闭设置面板

**移动端手势：** 左滑翻到下一章，右滑翻到上一章。

设置会先保存到浏览器本地，登录后自动同步到云端，跨设备保持一致。

::: tip
阅读章节可以获得 **5 经验值**，每日最多 10 次。
:::


## VIP 章节

作者可以为自己的长篇作品开启 VIP 章节：全书正文累计满 **6 万字**后，作者可把某一章及之后的章节设为 VIP，
读者使用净币解锁后**永久可读**。未解锁时页面只显示解锁引导（含字数、价格与按钮），**不会下发正文**；
段评接口与开放 API 同样会在未解锁时拒绝返回内容。

- 单章价格：`⌈本章字数 / 1000⌉ × 10` 净币（不足 1000 字按 1000 字计，最低 10 净币）
- 作者获得解锁消耗的 **80%**，其余为平台留存
- 目录页会用标签区分免费章节、未解锁的 VIP 章节与已解锁章节
- 目录页与未解锁章节页支持**批量解锁**：选择起止章节一次确认，已购章节自动跳过，整批扣费

完整规则见 [VIP 章节](/features/vip-chapter)。
