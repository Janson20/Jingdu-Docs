# 推荐与排序

净读的推荐全部在站内完成：不调用任何外部大模型，不把阅读偏好发送给第三方。首页作品流与书库共用同一套「多路召回 → 多指标打分 → 多样性重排」思路，但候选与指标不同。

## 一、首页作品流

首页的工程 / 帖子 / 博客 / 资源默认按算法排序，不再按发布时间混排。

### 1. 候选召回

- **热榜**：候选池内近 30 天互动表现好的内容；
- **新作**：最近发布、还没有足够曝光的内容；
- **兴趣**：与你的点赞、收藏、评论标签相近的内容；
- **关注**：你关注的作者发布的公开内容；
- **探索**：发布 72 小时内、阅读量还很低的新内容，保留固定曝光位。

每类内容取最近一批进入候选池（工程最多 100 条，其余最多 240 条），同一个 10 分钟窗口内复用，避免每次请求都扫全表。

### 2. 排序指标

| 指标 | 计算口径 | 作用 |
|---|---|---|
| 互动热度 | 点赞、评论、收藏、转发的加权综合 | 看内容是否真的被讨论、被收藏 |
| 互动转化 | 互动量与浏览量的比例（小样本做平滑） | 避免「1 次浏览 1 个赞 = 100%」 |
| 新鲜度 | 按 7 天半衰的时间衰减 | 老内容不会仅凭历史累计长期霸榜 |
| 增长速度 | 单位时间互动量 | 识别正在升温的内容 |
| 作者稳定性 | 同作者在候选池内的平均热度 | 让持续产出好内容的作者更稳定 |
| 个人兴趣 | 标签亲和度、作者亲和度、关注关系 | 登录后加入，冷启动时为 0 |
| 负向信号 | 已点赞 / 收藏 / 评论过的内容降权，自己发布的内容降权 | 减少重复与自推 |

所有计数先在**同类内容内部**做量级对齐，再混合四类内容，避免帖子天然比资源互动多而占据整页。

### 3. 重排规则

- **去重**：标签重合度越高，排序惩罚越大；
- **同作者上限**：首屏同一作者最多 2 条；
- **类型配额**：混合流里单一类型不超过约 55%；
- **探索位**：满足条件的新作会被放到第 6 位附近；
- **理由标签**：卡片会显示「你关注的人」「因为你喜欢某标签」「新作尝鲜」「讨论升温」「近期热门」等真实依据。

### 4. 分页与切换

- 推荐流按 10 分钟一个窗口生成，同一窗口内翻页顺序稳定；
- 搜索、标签、作者、分区筛选仍按发布时间排序，避免搜索结果被算法打散；
- 页面顶部提供「推荐 / 最新」切换，想按时间浏览随时可以切回。

## 二、书库

书库默认按推荐排序，顶部另有「为你推荐」区。

### 1. 书库排序

| 排序 | 说明 |
|---|---|
| 推荐（默认） | 综合质量、热度、留存、月票、书架、更新与个人偏好 |
| 最新 | 按最近更新时间倒序 |
| 热门 | 按近 30 天阅读人数、月票与好评率 |

### 2. 推荐会看哪些指标

| 类别 | 指标 |
|---|---|
| 质量 | 好评率（评价少时向 75% 收敛，避免一两票定生死） |
| 热度 | 近 30 天阅读人数、章节阅读量（长尾压缩后与其它指标对齐） |
| 留存 | 追读率、完读率、追更率、回访率；追读率只统计 VIP 前的免费章 |
| 支持 | 月票数、去重投票人数、月票转化；用投票人数避免一人多票堆高 |
| 意愿 | 书架收藏、收藏转化、催更 |
| 供给 | 最近更新时间、近 30 天更新章数；断更降权，新书有探索加分 |
| 个性 | 标签亲和度、作者亲和度；来自阅读历史、书架、好评与月票 |
| 负反馈 | 「不感兴趣」与差评标签降权；书库列表仍保留这本书，只往后排 |

小样本指标会自动降权：只有一两本书有数据的指标不会主导整页排序。

### 3. 推荐区

- 只在书库默认推荐排序且没有搜索 / 标签 / 同人筛选时显示；
- 每次展示 6 本，卡片给出真实理由与 1 个信号；
- 「换一批」在候选内轮换，不重新刷新指标表；
- 卡片支持「不感兴趣」，记录后同类推荐会减少。

### 4. 个性化开关

设置页的「使用我的阅读记录做个性化推荐」：

- 开启：首页作品流与书库排序都会使用你的阅读历史、书架、评价与月票偏好；
- 关闭：两处都只按全站质量与热度排序，已读作品仍会被排除在书库推荐区之外；
- 切换后立即失效旧画像缓存，不需要重新登录；
- 关闭不会影响阅读、书架、月票等功能。

## 三、冷启动与降级

- **未登录**：只使用全站质量、热度与新鲜度，不构造个人画像；
- **新用户**：有互动后逐步提高个性化权重，前几次不会因一两条记录就剧烈变化；
- **指标缺失**：书库用中性分参与排序，排序异常时回退默认顺序；推荐区为空时直接不渲染，不影响列表；
- **数据量不足**：小样本指标自动降权，避免冷门书因为「1 人 100% 追读」冲到第一。

## 四、数据与隐私

- 使用：阅读过的书籍与章节、阅读日期/次数、书架、评价、月票、催更、作品互动与「不感兴趣」反馈；
- 原始阅读事件保留 180 天，之后只保留聚合指标；
- 不采集正文内容、IP、设备指纹用于推荐；
- 推荐计算只发生在净读服务器，不把阅读历史或偏好发送给第三方 AI；
- 数据仅存储在净读服务器，不分享给第三方。
