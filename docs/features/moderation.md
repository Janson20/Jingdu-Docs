# 内容审核与发布风控

净读对**用户公开发布的内容**做两层检查：发布前的**算法风控**（频控、重复、灌水、广告特征、必拦词）与**AI 内容审核**（理解语义，判断涉政、色情、辱骂、诈骗、引流等）。两层都通过才会公开；AI 拿不准的内容转人工复核。

::: tip 一句话说明
正常创作与交流不受影响；空书、空章、复制粘贴刷字数、批量广告与刷屏会被算法直接拦下，语义违规交给 AI 与人工。
:::

## 覆盖范围

| 内容类型 | 算法风控 | AI 审核 | AI 不确定时 |
|---|---|---|---|
| 博客文章（新建/编辑） | 会 | 会 | 转人工，线上保持原样 |
| 博客投票问题/选项 | 会 | 随博客正文送审 | 随博客转人工或拒绝 |
| 论坛帖子（新建/编辑） | 会 | 会 | 转人工，线上保持原样 |
| 帖子 / 博客配图 | 会（大小/魔数） | 会（视觉模型逐张） | 不发布，提示更换图片 |
| 小说封面 | 会（大小/魔数） | 会（视觉模型逐张） | 不保存图片，提示更换封面（也可不上传封面） |
| 书籍信息（书名/简介/标签） | 会 | 会 | 转人工，通过后才建书 |
| 小说章节（新建/编辑/AI 生成保存） | 会 | 会，长章节全文分段 | 转人工，通过后才写入 |
| 博客/论坛评论 | 会 | 命中风险才送审 | 转人工，通过后才显示 |
| 段评（段落评论） | 会 | 命中风险才送审 | 转人工，通过后才显示 |
| 聊天室消息 | 会 | 命中风险才送审 | 直接拦下（聊天室没有人工队列） |
| 书评/评分 | 会 | 有文字时送审 | 转人工，通过后才计入 |
| 资源分享（新建/编辑） | 会 | 会 | 转人工，通过后才发布 |
| 个人简介 | 会 | 会 | 转人工，通过后才更新 |
| 工程分享 | 独立配额与风控 | 会（原有链路） | 工程管理页人工审核 |
| 私信 | 会 | **不会**（私密内容不发给第三方模型） | 不适用 |

未覆盖：AI 对话内容、书架私人备注、阅读历史等不公开的数据；工程/资源文件本体不进入本文本审核链路，仍由原有文件校验、举报与人工处置流程处理。帖子 / 博客配图与**小说封面**已接入视觉模型审核，图片在写入公开存储之前完成审核；存量封面在迁移存储时只做数据迁移，不重新送审（避免误判把已上架作品的封面摘掉），如发现问题可走举报与人工处置。

## 第一层：发布前算法风控

算法层不调用大模型，通常在几十毫秒内完成，用来挡住最明显的垃圾内容与刷量行为。

### 发布频率

按**账号**与**出口 IP** 双维度限制，游客只按 IP。主要默认值：

| 行为 | 账号限制 | IP 限制 |
|---|---|---|
| 新建书籍 | 3 本/天、2 本/小时 | 5 本/天 |
| 发布章节 | 30 章/天、10 章/小时、3 章/分钟 | 50 章/天 |
| 博客 | 6 篇/小时（另有等级每日上限） | 20 篇/天 |
| 论坛帖子 | 8 帖/小时（另有等级每日上限） | 20 帖/天 |
| 评论 | 5 条/分钟、80 条/天 | 40 条/天 |
| 游客评论 | 1 条/分钟、10 条/天 | 同上 |
| 书评 | 20 条/天 | - |
| 资源 | 5 个/天 | - |
| 聊天室 | 5 条/分钟、100 条/天 | - |
| 私信 | 10 条/分钟、200 条/天 | - |

### 重复与灌水

- 完全相同的内容重复提交会被拦截；博客/论坛允许同一篇内容的重试继承，但连续刷同样的内容超过阈值会被拦；
- 章节会与**本书已有章节**做近似比对，复制已有章节刷字数、刷 VIP 门槛会被拒绝；
- 重复行、重复段落、超长连续重复字符、信息量极低的文本会被判定为灌水；
- 占位文本（「测试」「待补充」「TODO」「暂无内容」等）不能作为章节正文。

### 广告与站外引流

- 评论、帖子、章节里出现多个链接、QQ/微信/电话/邮箱等联系方式，或「加群」「扫码」「代刷」「返利」等广告词，会提高风险分；
- 资源分享本身需要网盘链接，因此不会因为链接多就判违规，但仍会检查简介里的广告与违法资源；
- 新账号或游客带联系方式发布，会额外提高风险。

### 必拦词

平台维护一份必拦词库。命中即拦，不经过模型；评论、聊天室这类「低风险不送模型」的路径同样会过词库，不存在绕过。

### 自动冷却

同一账号或 IP 在 1 小时内被拦 **5 次**，自动禁发 **1 小时**；24 小时内被拦 **15 次**，自动禁发 **24 小时**。冷却期间所有发布入口都会提示剩余时间，管理员可在管理面板解除。

### 空书与空章治理

- 新建书籍可以先写书名与简介，但**没有正文的书是草稿**：不进书库、搜索、推荐、站点地图，不能投月票、不能写书评、不能催更；
- 每个账号最多同时保留 **3 本空草稿**，达到上限后需要先给其中一本发布正文或删除草稿；
- 空书不发放「发布」经验；第一章正文通过审核、书籍自动公开后才计入；
- 章节正文至少 **50 个有效字符**，且不能是占位/重复文本；
- AI 大纲书创建的是草稿与占位章节，只有在某章写入真实正文并通过审核后才会公开；
- 历史上已经存在的空书同样按草稿处理：作者自己在写作面板能看到，其他用户看不到。

## 第二层：AI 内容审核

AI 审核在算法层之后执行，只有算法放行（或判定需要模型复核）的内容才会送模型。模型输出统一为「通过 / 不通过 / 不确定」，并通过置信度阈值决定终态。

### 各类型的策略

- **博客（含投票问题/选项）、论坛、工程、书籍信息、书评、资源、个人简介**：每条都送主审；灰色内容再送复核模型；站内卡片与播放器令牌会先转成可读说明，投票问题/选项会并入审核文本；
- **小说章节**：按段落切分，**全文分段送审**（每段最多约 1.2 万字，单章最多 6 段）；任一段明确违规即整章不通过；全部段落通过才放行；
- **评论、段评、聊天室**：先过算法，只有命中风险特征（广告、联系方式、灌水、黑名单作者等）才送模型，正常短评论直接发布；
- **私信**：不送模型，只做算法风控。

### 章节审核关注什么

小说是虚构作品：暴力、犯罪、死亡、复仇、情感纠葛、暗黑设定属于正常文学表达，不会因为出现「杀」「死」「血」等字就判违规。真正拦截的是：露骨色情、未成年人性化、现实违法教程、极端主义宣扬、现实政治敏感、广告引流等。

### 结果与等待时间

- 多数博客/帖子 1~3 秒出结果；章节因分段送审可能更久；
- 评论通常即时发布，命中风险时才等待模型；
- AI 服务不可用时，公开内容转人工复核，不会误放；书籍/章节在人工通过前不会写入。

## 三种审核结果

### 1. 通过

内容立即发布（书籍仍需首章通过后才公开）。不会额外通知。

### 2. 不通过

页面会提示类目与一句话原因，内容不会入库。修改后可以重新提交；反复发布严重违规内容会触发冷却。

### 3. 转人工复核

AI 拿不准或服务繁忙时进入人工队列：

- 博客、帖子、书评、资源、个人简介：内容暂不发布，博客/帖子/资源可在「我的」页面看到审核中状态，其他类型通过后自动出现；
- 书籍信息：书籍暂不创建，管理员通过后才出现在写作面板；
- 章节：章节暂不写入，管理员通过后自动追加或更新；
- 评论、段评：评论暂不显示，管理员通过后自动出现；
- 聊天室：没有人工队列，不确定的消息直接拦下，修改后可重试。

## 管理端

管理员控制台 →「AI审核」页签：

- **运行概览**：今日送审量、放行/拦截、时延、抽检分歧率、算法/风控拦截数、当前禁发账号；
- **待人工队列**：书籍信息、章节、评论、书评、资源、个人简介、博客、帖子；通过后自动发布；
- **审核记录**：按类型、判定、状态筛选，可查看完整存证事件链；
- **必拦词库**：命中即拦；
- **作者名单**：trusted（轻量通道）/ normal / blocked（直接转人工）；
- **解除禁发**：输入作者 UUID 清除自动冷却；
- **存证校验**：校验审核存证哈希链完整性。

各类内容的审核阈值、频控与处置策略由平台统一维护，随站点配置调整。

## 隐私说明

- 公开内容（博客及投票问题/选项、帖子、书籍信息、章节、评论、段评、聊天室、书评、资源、简介、工程文字、**帖子与博客配图、小说封面**）会发送给第三方模型（DeepSeek、通义千问）做安全判断；配图与封面使用视觉模型逐张审核。播放器本身是第三方 iframe，不进入文本审核；其播放行为由对应平台负责。
- **私信不会发送给第三方模型**，只在本站做频率、重复与广告特征检测；
- 审核存证保存在站内数据库，用于合规留痕与申诉核查；私信不保存正文摘要，只保留哈希与命中特征；
- 审核记录不会用于推荐、画像或广告。

## 常见问题

**Q：我的书是空的，为什么在书库里搜不到？**
A：没有正文的书是草稿，只对作者自己可见。发布至少一章正文并通过审核后会自动公开。

**Q：为什么不能创建第四本空书？**
A：为了防止批量建空书占坑，每个账号最多同时保留 3 本空草稿。先给其中一本发布正文，或删除不用的草稿。

**Q：章节里写杀人、战争、犯罪会被拦吗？**
A：虚构情节本身不会。只有露骨色情、现实违法教程、未成年人性化、极端主义宣扬、广告引流等才会被拦。

**Q：为什么评论有时候秒发，有时候要等？**
A：正常短评论走算法直接发布；命中广告、联系方式、灌水等风险特征时才调用模型，所以会慢一点。

**Q：被自动禁发了怎么办？**
A：等待冷却结束，或通过[反馈中心](https://jingdu.productbridge.io)联系管理员解除。误伤可以在反馈中说明。

**Q：AI 审核会不会看我的私信？**
A：不会。私信不进入 AI 审核，也不会发送给第三方模型。

**Q：审核标准在哪里看？**
A：见[社区规范](https://jingdu.org/community)、[用户协议](https://jingdu.org/user-agreement)与[隐私政策](https://jingdu.org/privacy)。
