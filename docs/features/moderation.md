# AI 内容审核

净读的**博客文章**与**论坛帖子**在发布前会经过一次 AI 内容审核。审核由大模型自动完成，拿不准的内容再交给人工复核。目的是让社区里的内容保持干净、合规，同时不打扰正常的读书分享与交流。

::: tip 一句话说明
所有博客和帖子**先审后发**：审核通过才会出现在列表里，审核不通过会让你修改，暂时无法判断的会转人工复核（通过后自动发布，不需要你重新提交）。
:::

## 审核范围

| 内容类型 | 是否经过 AI 审核 |
|---|---|
| 博客文章（新发布、编辑修改） | ✅ 会 |
| 论坛帖子（新发布、编辑修改） | ✅ 会 |
| 评论、私信、聊天室、书籍章节、资源分享 | ❌ 不会（仍保留敏感词过滤等既有机制） |

## 发布后的三种结果

### 1. 审核通过

内容立即发布，和其他内容一样出现在博客列表或论坛列表里。这个过程通常在 1~3 秒内完成，你基本感觉不到。

### 2. 未通过

页面会直接提示未通过的原因（例如"涉政敏感""垃圾营销"等类目和一句话说明），内容**不会**被发布，也不会占用你的每日发布额度。

修改后重新提交即可再次进入审核。不会因为一次未通过就影响账号，但反复发布严重违规内容会导致账号被限制。

### 3. 转人工复核

少数内容模型无法确定（例如带有明显歧义的表述），或者审核服务临时繁忙时，会进入**人工复核队列**：

- 内容暂不发布，但已经保存，不需要你重新填写
- 在你的 **我的博客 / 我的帖子** 页面，可以看到「审核中」的记录
- 管理员复核通过后会**自动发布**，无需再次操作；复核不通过则会显示为「未通过」，并给出原因

## 在哪里查看审核状态

登录后进入 **我的博客** 或 **我的帖子**：

- **审核中** —— 已提交人工复核，等待处理
- **未通过** —— 已判定不通过，可以看到类目与原因，修改后可重新提交

审核通过并已发布的内容，正常显示在页面下方的文章/帖子列表中。

## 审核速度与偶发延迟

多数内容 1~3 秒出结果。如果遇到网络波动或模型服务繁忙，可能会出现：

- 结果等待时间变长（最多十几秒）
- 内容被转入人工复核

这段时间你的内容不会丢失，也不会被直接判为违规。

::: tip 重复提交会直接通过
如果你把一份**刚刚审核通过、内容完全相同**的文章或帖子再次提交（例如误触、重新粘贴），系统会直接判为通过，不再重复调用模型。
:::

## 关于隐私

审核需要把内容发送给第三方大语言模型服务（DeepSeek、通义千问）进行判断，与站内 AI 聊天、AI 推荐使用的是同一批服务，不额外收集其他信息。审核记录（提交内容、判定结果、时间）会保存在站内的审核存证库中，用于合规留痕。

如果你不希望内容被自动审核，请不要发布博客或论坛帖子；评论等其他内容不受影响。

## 常见问题

**Q：我的内容很正常，为什么没通过？**
A：模型判断可能出现偏差。请根据提示的原因适当修改（例如去掉可能引起误解的表述、广告性质的链接或联系方式），重新提交即可；如果认为判断明显有误，可以通过[反馈中心](https://jingdu.productbridge.io)告知我们。

**Q：为什么管理员发帖是秒过的？**
A：管理员账号有免模型审核通道（避免处理公告、通知等内容时被模型卡住），但仍然会经过必拦词与作者名单校验。

**Q：内容一直在"审核中"怎么办？**
A：人工复核依赖管理员在线处理。超过一天仍未处理，请通过[反馈中心](https://jingdu.productbridge.io)提醒。

**Q：审核会不会看我的私密内容？**
A：不会。审核只针对你提交发布的博客与帖子正文（含标题），评论、私信、聊天等内容不进入审核流程。

## 管理端说明（仅管理员）

管理面板 **管理员控制台 → AI审核** 页签提供：

- **待人工队列**：查看送审原文与 AI 判定依据，一键「通过」（正式发布）或「驳回」（不入库）
- **审核记录**：按时间/类型/判定筛选历史审核结果，可查看完整存证事件链
- **必拦词库**：命中即拦、不经过模型；建议只放合规底线词，避免误杀正常内容
- **作者名单**：`trusted`（走轻量通道）/ `normal` / `blocked`（内容直接转人工）
- **存证校验**：一键校验审核存证哈希链的完整性

审核相关的配置项（模型路由、阈值、抽检比例、超时）集中在 `config.py` 的 `MODERATION` 字典中，修改后重启服务生效。
