# 作品广场

作品广场把**工程、帖子、博客、资源**四类内容放进同一条浏览流，并用页内标签切换类别。发布页与「我的作品」使用同一套类别标签，不再需要在四个独立入口之间跳转。

## 浏览

- 入口：首页 `/`。
- 布局：类似 V 次元的三栏信息流——左侧热门标签与内容类型，中间单列作品流，右侧账号卡与推荐作品；窄屏自动收起两侧栏。
- 排序：默认按「互动热度 / 转化率 / 新鲜度 / 增长速度 / 作者稳定性」的算法排序，叠加标签、作者与关注兴趣，再做多样性重排；顶部可切换「推荐 / 最新」，搜索、标签、作者与分区页仍按时间排序。推荐卡片会显示真实理由标签。
- 卡片：包含作者头像、等级、类别、分区、发布时间、标题、摘要、配图、标签，以及统一的浏览 / 评论 / 点赞 / 收藏 / 转发数据。
- 页内标签：全部 / 工程 / 帖子 / 博客 / 资源。点击标签只替换列表，不刷新页面，地址栏同步为 `/?type=project` 这样的地址。
- 分区标签：切到帖子或博客时，类别标签下方显示该类的分区（全部 / 杂谈 / ...）。点击分区同样只替换列表，地址栏同步 `section` 参数。
- 无限滚动：首屏随页面直接给出，滚动到接近底部时自动请求下一页并追加；每页 12 件。
- 搜索：顶部搜索框按标题、简介、正文或标签检索当前类别；搜索结果仍保留类别标签。
- 作者筛选：个人中心的「TA的作品」会打开 `/?author=<uuid>`，只显示该用户公开的作品。
- 旧入口：`/project`、`/forum`、`/blog`、`/resource/` 仍可访问，但渲染的是同一作品流，并自动定位到对应类别；旧收藏链接不会失效。
- 无 JavaScript 时：首屏与分页链接仍可使用。

## 发布

- 入口：`/publish`（需登录），顶栏「发布」与个人中心「发布作品」都会到这里。
- 页内标签：工程 / 帖子 / 博客 / 资源。四个表单同时存在于页面中，切换标签只显示对应的表单，不会丢失其他表单里已经填写的内容。
- 提交仍走各模块原有的创建接口（`/project/create`、`/forum/create`、`/blog/create`、`/resource/create`），因此审核、每日限额、工程配额、文件上传与净币规则完全不变。
- 校验失败时会回到对应类别的表单并保留已填内容；成功后回到作品流或「我的作品」查看结果。
- 帖子与博客支持分区与标签：发帖 / 发博客时选择分区（默认 **杂谈**），可填最多 5 个标签；卡片和详情页会显示分区与标签，点击可筛选。未选择分区时按 **杂谈** 处理。
- 帖子与博客支持配图：在 `/publish` 的帖子 / 博客表单，或 `/forum/create`、`/blog/create` 中选择最多 9 张图片（JPG / PNG / WebP，单张 ≤5 MB）。图片先做大小与文件头校验，再经过视觉模型 AI 审核；明确通过后才写入公开存储，未通过或无法确认的图片不会发布。
- 配图可编辑：帖子与博客的编辑页会列出已有图片，可勾选删除并补充新图；保留的旧图不重复审核，新增图片仍需 AI 审核。博客配图还可以插入正文，详见 [博客系统](/features/blog#正文内嵌配图)。
- 直接访问旧的 `/project/create`、`/forum/create`、`/blog/create`、`/resource/create` 也可以，页面顶部同样有类别标签。

## 我的作品

- 入口：个人中心（`/user/<uuid>`）的「我的作品」、顶栏用户下拉菜单，或直接访问 `/my/works`。
- 默认显示全部类别，也可按工程 / 帖子 / 博客 / 资源筛选；每类显示数量角标。
- 每条作品提供「编辑 / 删除」；工程还会显示审核状态（待审核、审核中、未通过、已下架）。
- 博客、帖子、资源在审核阶段尚未公开，页面顶部「审核记录」会展示审核中与未通过的内容及原因。
- 别人访问你的个人中心时看到的是「TA的作品」，链接到只含公开内容的作者筛选页。

## 我的收藏与我的点赞

- 入口：顶栏用户下拉菜单的「我的收藏」「我的点赞」，或直接访问 `/my/bookmarks`、`/my/likes`。
- 两个页面覆盖帖子、博客、资源三类内容，显示类型、标题、作者、时间和真实互动数。
- 收藏与点赞以统一互动记录为准；旧论坛的「我的点赞」「我的收藏」入口继续保留。

## 统一互动

帖子、博客、资源共用一套互动栏与评论区：点赞、点踩、收藏、转发、评论。计数统一计算，旧模块的计数只作为热榜缓存并同步更新；删除内容时会清理对应的收藏、转发、评论与历史基数。

## 权限与可见性

| 类别 | 公开作品流 | 我的作品 |
|------|------------|----------|
| 工程 | 仅审核通过 | 全部状态，含审核中 / 未通过 |
| 帖子 | 已通过审核并入库 | 已发布内容 + 审核记录 |
| 博客 | 已通过审核并入库 | 已发布内容 + 审核记录 |
| 资源 | 已发布内容 | 已发布内容 + 审核记录 |
