# 作品广场

作品广场把**工程、帖子、博客、资源**四类内容放进同一条浏览流，并用页内标签切换类别。发布页与「我的作品」使用同一套类别标签，不再需要在四个独立入口之间跳转。

## 浏览

- 入口：首页 `/`。
- 布局：类似 V 次元的三栏信息流——左侧热门标签与内容类型，中间单列作品流，右侧账号卡与最新作品；窄屏自动收起两侧栏。
- 卡片：包含作者头像、等级、类别、分区、发布时间、标题、摘要、配图、标签与浏览 / 回复 / 点赞 / 收藏数据。
- 页内标签：全部 / 工程 / 帖子 / 博客 / 资源。点击标签只替换列表，不刷新页面，地址栏同步为 `/?type=project` 这样的地址。
- 分区标签：切到帖子或博客时，类别标签下方显示该类的分区（全部 / 杂谈 / ...）。点击分区同样只替换列表，地址栏同步 `section` 参数。
- 无限滚动：首屏由服务端直出，滚动到接近底部时自动请求下一页并追加；每页 12 件。
- 搜索：顶部搜索框按标题、简介、正文或标签检索当前类别；搜索结果仍保留类别标签。
- 作者筛选：个人中心的「TA的作品」会打开 `/?author=<uuid>`，只显示该用户公开的作品。
- 旧入口：`/project`、`/forum`、`/blog`、`/resource/` 仍可访问，但渲染的是同一作品流，并自动定位到对应类别；旧收藏链接不会失效。
- 无 JavaScript 时：首屏与服务端分页链接仍可使用。

## 发布

- 入口：`/publish`（需登录），顶栏「发布」与个人中心「发布作品」都会到这里。
- 页内标签：工程 / 帖子 / 博客 / 资源。四个表单同时存在于页面中，切换标签只显示对应的表单，不会丢失其他表单里已经填写的内容。
- 提交仍走各模块原有的创建接口（`/project/create`、`/forum/create`、`/blog/create`、`/resource/create`），因此审核、每日限额、工程配额、文件上传与净币规则完全不变。
- 校验失败时会回到对应类别的表单并保留已填内容；成功后回到作品流或「我的作品」查看结果。
- 帖子与博客支持分区与标签：发帖 / 发博客时选择分区（默认 **杂谈**），可填最多 5 个标签；卡片和详情页会显示分区与标签，点击可筛选。未选择分区时服务端回落到杂谈。
- 帖子与博客支持配图：在 `/publish` 的帖子 / 博客表单，或 `/forum/create`、`/blog/create` 中选择最多 9 张图片（JPG / PNG / WebP，单张 ≤5 MB）。图片先做大小与魔数校验，再经过视觉模型 AI 审核；明确通过后才写入公开 OSS 桶，未通过或无法确认的图片不会发布。
- 配图可编辑：帖子与博客的编辑页会列出已有图片，可勾选删除并补充新图；保留的旧图不重复审核，新增图片仍需 AI 审核。
- 直接访问旧的 `/project/create`、`/forum/create`、`/blog/create`、`/resource/create` 也可以，页面顶部同样有类别标签。

## 我的作品

- 入口：个人中心（`/user/<uuid>`）的「我的作品」、顶栏用户下拉菜单，或直接访问 `/my/works`。
- 默认显示全部类别，也可按工程 / 帖子 / 博客 / 资源筛选；每类显示数量角标。
- 每条作品提供「编辑 / 删除」；工程还会显示审核状态（待审核、审核中、未通过、已下架）。
- 博客、帖子、资源在审核阶段尚未写入公开表，页面顶部「审核记录」会展示审核中与未通过的内容及原因。
- 别人访问你的个人中心时看到的是「TA的作品」，链接到只含公开内容的作者筛选页。

## 权限与可见性

| 类别 | 公开作品流 | 我的作品 |
|------|------------|----------|
| 工程 | 仅审核通过（`approved`） | 全部状态，含审核中 / 未通过 |
| 帖子 | 已通过审核并入库 | 已发布内容 + 审核记录 |
| 博客 | 已通过审核并入库 | 已发布内容 + 审核记录 |
| 资源 | 已发布内容 | 已发布内容 + 审核记录 |

## 维护者备注

- 数据聚合：`works_data.py`，统一时间排序、纯文本摘要、作者名、分区 / 标签与统计字段。
- 分区词表：`content_sections.py`（帖子 / 博客分别定义，默认「杂谈」）；标签规则复用 `tag_utils.py`。
- 页面与接口：`routes/works.py`（`/publish`、`/my/works`、`/api/works`）。
- 前端：`static/js/works-feed.js`（页内切换、无限滚动、列表 / 瀑布流布局）、`static/js/publish-tabs.js`（发布页标签、字数统计、标签词表）、`static/js/forum-images.js`（配图预览与前端预检）、`static/css/works.css`。  
- 配图：`content_images.py`（通用校验、OSS 公开桶、CDN URL 与图片表仓库）、`forum_images.py`（`forum_post_images`）、`blog_images.py`（`blog_post_images`）、`image_review.py`（视觉模型审核，含小说封面）与 `book_covers.py`（小说封面：审核后写入 OSS、地址解析与存量迁移）。
- 配图查看：`static/js/image-lightbox.js`（详情页页内放大，支持多图切换、键盘 / 触屏操作）与 `static/css/detail.css` 中的 `.img-lightbox` 样式。
- CDN 防盗链：`cdn.jingdu.org` 会校验 Referer。所有配图与小说封面的 `<img>`、「查看原图」链接必须带 `referrerpolicy="no-referrer"`，否则从 localhost / 预览域名访问会 403。
- 卡片模板：`templates/_work_card.html` 与 `templates/_work_cards.html`，服务端与接口共用，避免前后端各维护一套卡片 HTML。
- 计数缓存 60 秒；新发布的内容会立即出现在列表里，但标签角标最多延迟 60 秒。
