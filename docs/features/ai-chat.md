# AI 聊天

净读集成了 DeepSeek 和 Qwen 大语言模型，提供智能 AI 对话服务。

::: tip 新手引导
如果你是第一次使用净读AI，推荐先阅读 [AI功能保姆级教程](/ai_tutorial)，从注册到精通，手把手带你入门。

## 首次使用

### 开通服务

1. 登录后，点击导航栏的 **AI 聊天** 入口
2. 首次使用需要阅读并同意 **AI 服务条款**
3. 点击 **开启服务** 按钮

## 积分系统

AI 聊天使用 **基于 token 的阶梯计费** 制，1 积分 = 0.01 元人民币。

### 计费规则

每次请求根据实际的 **输入 token 数** 和 **输出 token 数** 计算积分，向上取整（最低 1 积分）。

开启 **联网搜索** 时，每次成功的搜索或网页抓取还会额外收取 **1 积分/次**（失败、空结果、缓存命中不收费），与 token 费用合并为一次扣费。**站内搜索** 读取的是本站数据，不按次收费，仅正常计 token 费用。

采用 **超额累进阶梯** 计费，用量越高，后续 token 的兑换率越高（单价越低）：

| 阶梯 | token 用量范围 |
|------|----------------|
| 第一阶梯 | 0 ~ 10,000 |
| 第二阶梯 | 10,001 ~ 100,000 |
| 第三阶梯 | 100,001 及以上 |

## 使用 AI 聊天

1. 进入 **AI 聊天** 页面
2. 选择 AI 模型（下拉菜单）
3. 在输入框中输入你的问题
4. 点击发送按钮或按回车

### 输入与发送

- **Enter 发送**、**Shift+Enter 换行**（中文输入法候选确认不会被误触发送）
- 输入框会随内容**自动增高**（初始约 2 行，最多约 6 行），超出后内部滚动
- 生成期间发送按钮变为红色**停止**按钮，点击可随时中止生成
- 中止后已生成的内容会保留并记录到对话历史

### 流式输出

AI 回答采用 **流式输出**，内容边生成边实时显示，无需等待完整回答：

- 回答内容逐字生成，已完成的部分立即渲染为 Markdown 排版
- 长回答使用增量渲染优化，即使内容很长也不会卡顿
- 代码块在完整生成前以纯文本显示，生成完毕后自动渲染为带高亮的代码块
- 表格、公式、流程图等内容在回答结束后自动排版美化
- **两阶段超时保护**：推理等待阶段最长 10 分钟；开始输出后若超过 5 分钟无新内容自动中止并提示
- 阅读历史内容时**自动滚动会暂停**，不会把你强行拉回底部；回到底部后自动恢复跟随

### 页面加载优化

- 所有渲染库（Markdown、代码高亮、公式、图表）已**自托管到站内**，不再依赖外部 CDN，国内访问更快更稳
- 流程图库（Mermaid）**按需加载**：仅当消息包含流程图代码块并点击预览时才加载，不拖慢首屏
- 其余渲染库**并行下载**（defer），不阻塞页面解析与首屏渲染
- 大量历史消息恢复时**分帧渐进渲染**，页面不再长时间卡顿

### 用户环境感知

AI 的系统提示词会自动附带**用户当前环境信息**，让回答更贴合浏览场景：

- **浏览方向** — 自动检测浏览窗口是竖屏还是横屏：竖屏时 AI 会尽量按**竖版**设计 HTML 内容（如演示文稿）和 Mermaid 图表，横屏时则按横版设计，避免内容在小屏上溢出
- **设备类型** — 自动识别你正在使用**移动端**还是**桌面端**，回答会考虑屏幕宽度、触控操作等差异
- **当前日期** — 提示词中包含当天的日期（年月日），涉及时效性的回答更准确
- **IP 属地** — 精确到省/市，回答涉及本地化内容（如天气、地方习俗、本地政策）时更贴近用户所在地
- **平台信息** — 提示词中还包含净读平台的简介、核心功能与反馈渠道，询问净读相关问题时回答更准确，需要反馈时可直接引导至反馈中心

环境信息在每次发送消息时**实时检测**（旋转屏幕后无需刷新，立即生效），仅用于优化回答，不属于对话内容，不会展示在聊天记录中。

::: tip
环境信息仅在系统提示词中生效，不会保存到聊天记录或数据库中；IP 属地仅精确到省/市，不涉及具体地址。
:::

### 站内搜索

AI 聊天内置 **站内搜索** 工具（默认开启），AI 会自行判断何时检索，并可直接阅读站内正文：

- **检索范围**：书库（书名 / 作者 / 简介 / 标签）、博客、论坛、工程分享、资源分享；可以只查某一类，也可以全站检索
- **查看正文**：书籍可读取目录与指定章节，博客与论坛可读全文和部分评论，工程与资源可读取介绍、文件与下载信息
- **原生工具调用**：与联网搜索一样由模型决定检索时机和范围；你不需要手动选择，也可以直接在提问中点名「论坛」「工程」等范围
- **引用来源**：站内结果同样带 `[1]`、`[2]` 编号，点击编号可直接打开站内页面；参考来源卡片会标注「站内内容 / 站内正文」
- **VIP 保护**：VIP 章节若尚未解锁，AI 只会看到锁定说明，不会读取或编造正文
- **不额外计费**：站内搜索读取本站数据，不按次收费，仅正常计 token 费用

| 项目 | 规则 |
|------|------|
| 检索次数 | 每条消息最多 **4 次** |
| 查看内容 | 每条消息最多 **8 篇** |
| 计费 | 不额外收费（仅 token 费用） |
| 与联网搜索 | 可以同时开启，两类来源共用一套引用编号 |

::: tip
站内搜索只读取**已发布**的内容：审核中的博客 / 帖子、未通过审核或已下架的工程不会出现在结果里。
:::

### 联网搜索

AI 聊天支持 **联网搜索**（默认开启），开启后 AI 可以检索公开网页，并在回答中标注来源。

#### 使用方式

1. 登录后，在 AI 聊天页面左侧的功能开关中保持 **联网搜索** 开启（默认开启）
2. 正常提问，例如「今天北京天气怎么样」「最近发布了什么新手机」
3. 涉及新闻、实时数据、价格、版本、政策、赛事、天气、人物近况等时效性问题时，AI 会自行调用搜索工具
4. 需要阅读网页原文细节时，AI 会继续抓取搜索结果中的具体页面
5. 回答中的引用会以 `[1]`、`[2]` 标注，**点击编号可直接打开对应来源**；回答下方展示 **参考来源** 卡片

#### 计费与限制

| 项目 | 规则 |
|------|------|
| 搜索次数 | 每条消息最多 **4 次** |
| 网页抓取次数 | 每条消息最多 **10 个网页** |
| 计费 | 每次**成功**的搜索或抓取额外 **1 积分**，与 token 费用合并扣除 |
| 不收费的情况 | 搜索无结果、网页无正文、调用失败、命中本地缓存 |

> 联网搜索按实际发起的成功调用计费，官方单价约 0.005 元/次；失败重试和空结果不向用户收费。

#### 说明

- 仅登录用户可用；未登录的免费体验不提供联网搜索与站内搜索
- **文档生成 / FIM 模式**不会走原生工具调用，开启后联网搜索与站内搜索开关会暂时禁用（不改写你的选择），退出后恢复原来的状态
- 联网搜索与站内搜索可以同时开启，AI 会自行决定查站内还是查互联网
- 搜索与网页读取过程会显示在回答上方的 **「已思考」轨迹** 中，包括搜索条数、站点图标与已浏览页面链接；站内检索与查看会以「站内找到 N 条内容」「查看了 N 篇站内内容」展示
- 网页内容属于外部数据，可能存在错误、过时或被篡改的信息；AI 会尽量基于来源回答，但重要信息仍建议点击来源核对
- 开启联网搜索后，搜索词会发送给 DeepSeek 的搜索服务处理，详见 [隐私政策](/privacy)
- 搜索来源会随对话一起保存在浏览器本地，导出的 HTML / JSON 备份中也会包含来源列表

### AI 人设

AI 聊天支持 **人设系统**，可以让 AI 扮演特定角色，提供更专业的回答。

#### 使用方式

1. 在左侧边栏的 **使用人设** 下拉菜单中选择角色
2. 选择后，聊天区域会显示该人设的推荐问题
3. 点击推荐问题即可自动填入输入框
4. 选择 **默认（无人设）** 可恢复通用 AI 助手模式
5. 人设切换后，之前对话的上下文仍然保留

#### 可选人设

| 人设 | 说明 |
|------|------|
| 全能写作助手 | 精通商务邮件、学术论文、营销文案、创意故事等文体 |
| 编程随行导师 | 精通 Python、JavaScript、Java、Web 开发等，帮助调试和学习 |
| 高效学习教练 | 精通费曼学习法、间隔重复等学习策略，制定学习计划 |
| 心灵树洞伙伴 | 基于积极心理学提供情绪支持和倾听 |
| 私人健身顾问 | 根据身体状况和目标设计个性化训练计划 |
| 法律百事通 | 解释法律概念，指导法律文书撰写 |
| 营养饮食规划师 | 定制个性化饮食计划与食谱 |
| 职场领航者 | 简历优化、面试模拟、职业路径规划 |
| 旅行智囊团 | 推荐目的地、规划行程、提供旅行建议 |
| 生活妙招管家 | 家居收纳、时间管理、理财小技巧 |

> 人设系统通过系统提示词（System Prompt）生效，每次对话会将对应人设的提示词发送给 AI 模型。

### FIM 补全模式

使用 DeepSeek 模型时，可以开启 **FIM 补全模式**（Fill In the Middle）：

- 提供 **开头** 和 **结尾**（可选），AI 补全中间的内容
- 适用于内容续写、代码补全等场景
- 开头和结尾总长度不超过 1000 字符
- 计费方式与普通聊天相同，基于实际 token 用量阶梯计费

::: tip
FIM 补全仅支持 DeepSeek 系列模型（deepseek-flash、deepseek-v4-pro）。旧版模型名称（deepseek-chat、deepseek-reasoner、deepseek-v4-flash、deepseek-v4-flash-vision-exp）仍可兼容使用。
:::

### 输出长度

- 登录后使用 AI 功能时，**单次输出长度不设上限**：模型会一直生成到自然结束或上下文用尽，长篇回答、长代码、长章节不会再被固定长度截断
- 未登录的免费体验仍保留 **2000 tokens** 的输出上限（详见 [免费 API](/free_api)）
- 输出越长消耗的积分越多，请留意余额

### 对话轮数限制

- 每次对话最多支持 **50 轮**（一问一答为 1 轮）
- 达到上限后需要清空对话才能继续
- 清空对话后历史记录不会保留

### 聊天历史（多会话）

- 聊天记录**仅保存在浏览器本地**（localStorage），不会上传到服务器
- 支持**多会话管理**：可新建、切换、重命名、删除会话，每个会话独立保存模型、人设、开关等设置
- **全文搜索**：在侧边栏搜索框输入关键词，可直接检索所有会话的标题、用户消息和 AI 消息，点击结果可跳转到对应会话并高亮命中消息
- 每个会话最多支持 50 轮对话；图片消息中的图片以 base64 形式随会话保存在本地
- 旧版单会话聊天记录会自动迁移为第一个会话

### 查询余额

点击聊天页面的余额显示区域，或访问充值页面查看当前积分余额。

仪表盘数据来源于每次请求的实际 token 用量，完全透明可审计。

### 视觉模型（图片理解）

**DeepSeek-V4.1-Flash**（`deepseek-flash`）由原 **DeepSeek V4 Flash** 与 **DeepSeek V4 Flash Vision** 合并升级而来，一个模型同时具备通用对话与图片理解能力：

- **图片描述与问答** — 上传图片后直接提问"这张图里有什么"
- **截图文字识别（OCR）** — 提取截图、照片中的文字内容
- **图表分析** — 理解柱状图、折线图、饼图等数据可视化内容
- 纯文本对话能力完整保留，原先需要切换模型才能识图的操作现在一步完成

**使用方式：**

1. 在"AI模型"下拉菜单中选择 **DeepSeek-V4.1-Flash**（或 Qwen 系列模型）
2. 点击上传按钮选择图片，或直接**粘贴截图**、**拖拽图片**到聊天框
3. 输入问题并发送，AI 会结合图片内容回答

**说明：**

- 支持 **JPEG、PNG、GIF、WebP** 格式（以文件实际内容识别，与扩展名无关）
- 图片会转换为 Token 计费，单张图片最多约 **384 个 Token**，计费规则与文本完全一致
- 网页端图片通过 DeepSeek Files API 引用，支持最大 64 MiB 图片，对话结束后自动清理
- 上传的图片仅用于本次对话，不会保存在服务器上

::: tip
图片仅支持在用户消息中使用。切换模型时，已上传的图片附件会自动清除。
:::

## 方向舵：不重问，直接调整回答

对 AI 的回答不满意时，通常的做法是**重新提问**——但这样会丢掉已经对的部分，
而且得把要求再说一遍。**方向舵**换了个思路：

> 把当前回答当成一个**可编辑的对象**，原始问题保持不动，你只施加「往哪个方向改」
> 的信号，AI 在这个回答上做增量编辑。

一句话概括：**从「重新提问」变成「调舵」。**

### 打开方式

每条 AI 回答的左下角都有一个 **调整** 按钮（在「复制为Markdown」旁边）。
点击后，回答下方展开方向舵面板。

### 五种调整方式

#### 1. 方向滑块

面板顶部是五个滑块，拖动即可表达方向，松手前就能看到当前值：

| 滑块 | 低端 | 高端 | 控制的是 |
|------|------|------|----------|
| 篇幅 | 更短 | 更长 | 总字数与篇幅 |
| 表达 | 通俗 | 专业 | 词汇难度、术语密度 |
| 具体度 | 抽象 | 具体 | 实例、场景、细节的数量 |
| 立场 | 中立 | 批判 | 质疑、局限、风险的比重 |
| 信息密度 | 简洁 | 详细 | 论点展开度与子问题覆盖度 |

「篇幅」和「信息密度」是两条独立的轴：一段话可以又长又空，也可以又短又密。

::: tip 滑块是「位置」不是「叠加」
滑块显示的是**你想要的新位置**。同一个位置拖两次不会翻倍，
把它拖回中间就是取消这个方向。
:::

#### 2. 快捷标签

不想拖滑块时，直接点标签：

**加例子**、**加数据**、**删冗余**、**换比喻**、**面向小白**、**列成步骤**、
**列成表格**、**加小标题**、**结论先行**、**更严谨**、**更温和**

标签会自动展开成对应的方向与约束（例如「加数据」会同时要求
「没有把握时写明需查证，严禁编造」）。

#### 3. 局部调整

只想改其中一段，不想动全文时：

1. 点击面板上的 **点选段落** 按钮，回答会被拆成若干可点选的段落
2. 在回答里点击要处理的段落（可以多选）
3. 每段右侧有 **保留 / 重写 / 扩写 / 删掉** 四个按钮，直接标记
4. 未被标记的段落会**逐字保留**，AI 不会顺手改掉

#### 4. 补充说明

用一句话说清方向，例如：

- `再通俗点，少术语，加两个例子`
- `往这个方向再走一点`（在当前方向上继续加强）
- `有点过了`（把当前方向往回拉）
- `别用比喻`

系统会先按内置词表解析（速度快、不额外计费），词表覆盖不到的表述才交给模型解析。

#### 5. 风格样本

把你想要的风格粘进去（例如「短句为主，先说结论，少用形容词」），
AI 会模仿这个样本的句式与语气，但不会照抄内容。

### 应用之后会发生什么

点击 **应用到答案** 后，回答会**原地替换**为新版本，并展开三块反馈：

1. **变更摘要** — 一句话说明改了什么，例如「篇幅减少 38%，新增 2 个例子，核心定义保留」
2. **方向符合度** — 0~100 分，逐维度显示每个方向是「达成 / 部分达成 / 未变化 / 反向」。
   分数由**确定性算法**算出（字数、例子数、术语密度、命题密度等），同一份文本永远得同一个分
3. **差异对比** — 逐段列出改写前后，每段都可以 **接受 / 拒绝**，也可以「全部接受」「全部拒绝」

#### 差异对比怎么用

差异面板是**先预览、再定稿**两步：

1. 点某一段的 **接受 / 拒绝**（或「全部接受 / 全部拒绝」）时，上方的答案会**立刻**按新取舍重排，
   方便你直接看到结果。此时状态显示为 **预览中**，取舍是纯本地计算，**不再消耗积分**
2. 满意后点 **应用所选** 定稿：差异列表会**自动收起**，替换成一行摘要
   （例如「已应用所选取舍：接受 2 段，拒绝 1 段」），按钮变为 **重新编辑差异**
3. 想再调，点「重新编辑差异」展开列表继续取舍；只要又动了任何一段，状态就回到「预览中」

### 事实核对

定向改写最怕的是 AI 借「调整」之名把事实也改了。因此每次改写后系统都会做一次**确定性比对**：

- 原文里的**数字**在改写后是否消失
- 改写后是否**凭空多出**原文没有的数字
- 你明确要求保留的内容是否还在

命中会以醒目提示标出，你可以直接在差异视图里点「拒绝」把那一段退回去。

### 版本回溯

每次调整都会存成一个新版本，回答底部出现版本切换器：

- 用 `‹` `›` 在版本之间来回切换，标题处可展开完整版本列表
- **首版永远保留**，随时可以退回去
- 每条回答最多保留 **5 个普通版本**，被淘汰时若你正在查看该版本会自动转为收藏
- 版本保存在**你自己的浏览器**里（localStorage），不会上传到服务器

### 方向冲突时会怎样

如果同时要求「更短」和「多给例子」，这是互相矛盾的方向。系统不会替你猜，
而是**先停下来问你**：优先缩短，还是优先信息量？选定之后再生成一版。

- **这一轮不消耗积分**，也不调用生成模型
- 你的选择会被记住，下次遇到同类冲突自动沿用，不再反复询问

### 给我两版

拿不定主意时，面板上的 **给我两版** 会同时生成：

- **A 版（方向优先）** — 方向与保留冲突时优先满足方向，改动幅度更大
- **B 版（保留优先）** — 优先保留原有内容与结构，只做最小必要改动

两版并排展示，选一版作为新的当前答案。

::: warning 会产生两次费用
同时生成两版意味着两次完整的改写调用，各计一次消耗。点击前会二次确认。
:::

### 计费与限制

- 方向舵调整按**普通对话规则计费**（基于 token 的阶梯计费，最低 1 积分）
- **不计入 50 轮对话上限**，也不会推动「累计对话轮数」每日任务
- 变更摘要的调用费用已包含在同一次消耗里，不额外收取
- 积分不足时会提示充值，不会生成半截结果
- **访客（未登录）暂不可用**，登录后即可使用

### 偏好记忆

系统会记录你常用的方向标签。面板上会出现 **沿用上次方向** 与常用标签快捷入口。
偏好只存在本地，随时可以在面板的 **重置** 中清空。

::: tip 停止生成
调整过程中随时可以点发送按钮旁的 **停止**。半成品不会自动写进版本栈——
系统会问你要「保留为未完成版本」还是「丢弃」。
:::

### 暂不适用的场景

- **文档生成模式**的回答是文件产物，不提供方向舵调整，需要重新生成
- 带图片的提问可以正常调整：图片内容已经体现在当前回答里，重写时不需要重新读图

## LaTeX 数学公式

AI 聊天支持渲染 LaTeX 数学公式。对话中的数学表达式会自动渲染为美观的公式：

- **行内公式**：`$...$` 或 `\(...\)`
- **块级公式**：`$$...$$` 或 `\[...\]`

例如：
- `$\frac{a}{b}$` 渲染为行内分数
- `$$\int_0^1 x^2 dx$$` 渲染为独立的积分公式

> 代码块里的 `$` 不会被当成公式：``` 围栏内的内容始终按代码原文显示（例如 JS 模板串 `` `${a}_${b}` ``），可直接复制运行。

## 文档生成（Word / PPT）

净读 AI 的文档生成模式支持用一句话生成可下载的 `.docx` 或 `.pptx` 文件，直接用 Word、WPS、PowerPoint 打开编辑。

### 实现方式

文档生成不是套模板，也不是让模型输出 YAML：模型根据需求直接编写 python-docx / python-pptx 排版代码，服务端在隔离子进程中执行，校验文件结构后交付。执行或校验失败时，会把错误信息回灌给模型自动修复，默认最多尝试 3 次。因此版式能力上限由这两个库决定，可以生成封面、章节标题、表格、原生图表、时间轴、对比页等结构。

### 如何使用

1. 在 AI 聊天页面左侧，打开 **文档生成** 开关（仅登录用户可用）
2. 选择格式：**自动判断格式** / **Word 文档（.docx）** / **PPT 演示文稿（.pptx）**
3. 在对话框描述需求，例如「做一份 2026 年 Q3 销售复盘 PPT，重点讲渠道变化与下季度计划」
4. 生成完成后，点击 **下载 DOCX / PPTX** 按钮保存到本地
5. 文件在服务器保留 **1 天**，请及时下载

### 内容建议

- **Word 文档**：适合周报、方案、制度、合同、论文、简历、说明书等以段落论述为主的内容；默认 3-6 个章节
- **PPT 演示文稿**：适合汇报、分享、宣讲、培训、课件等以要点展示为主的内容；默认 8-12 页
- 可以指定页数、章节、配色、字体、受众和语气；请尽量提供真实数据与明确结论，AI 不会替你编造业务数字
- 生成环境没有图片素材，也禁止联网下载，因此 **不支持插入图片**；数据请用表格或原生图表表达
- 文档生成模式 **不支持图片附件**；文本文件会作为需求内容一并发送

### 自动修复与计费

- 生成过程包含「设计内容 → 编写排版代码 → 执行代码 → 校验文件」四步；失败会自动重试
- 每一轮模型调用都按正常 **token 计费**（包括自动修复轮）
- 文件生成成功后在 token 费用之外额外收取 **5 积分** 文件生成费；失败不收取这 5 积分
- 下载文件不额外收费

### 使用限制

- 仅登录用户可用，且需要已开启 AI 服务
- 文档生成使用专用系统规则，人设提示词不会改变排版协议
- 与 **联网搜索 / 补全模式（FIM）** 互斥；开启文档生成后联网搜索会暂时禁用
- 生成文件属于一次性产物，不提供方向舵调整；需要修改时请重新描述需求
- 生成质量依赖所选模型；遇到失败可换模型或把需求拆小后重试

### 调用方式

在请求头中携带 `Authorization: Bearer sk-xxxx` 即可替代登录 Token 调用 DeepSeek API 代理。支持所有 `/api/deepseek/*` 路径。

### 注意事项

- 每个 Key 可单独设置每分钟速率限制（1-1000 次）
- 可在开发者面板中随时暂停或删除 Key
