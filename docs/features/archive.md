# 歌姬档案

分两层：**引擎**（技术路线）与**声库**（具体某个声音）。内容都是人工维护的，
不是用户投稿区——声源、引擎型号写错比没有更糟。

## 一、收录什么

| 层 | 收录内容 |
| --- | --- |
| 引擎 | 开发方、发布时间、授权方式、支持平台、优缺点、典型制作流程 |
| 声库 | 所属引擎系列、语言、声源、发布日期、调校要点 |

每个声库还可以带一组代表作（歌名、专辑与跳转链接），以及首页推荐位。

## 二、页面对应

- `/vocaloid/`：引擎卡片 + 按引擎系列分组的声库列表，可按系列筛选。
- `/vocaloid/<slug>`：单个声库，含调校要点与代表作。
- `/vocaloid/engine/<slug>`：单个引擎，含优缺点、流程，以及该系列下的声库。

声库页与引擎页互相跳转；首页只展示推荐的 6 条（不足时按引擎轮流补齐），
避免首页永远只出现同一系列。

## 三、代表作：来源与更新

代表作取自网易云音乐的公开信息，每位取前 10 首，页面展示歌名、专辑与跳转链接。

**只展示歌名、歌曲编号与链接，不下载、不转存任何音频。**

榜单是短期热门，所以不写死：每天自动刷新一次（默认 04:30，本地时间）。

- 页面打开时读的是最近一次刷新的结果，不会临时联网；
- 当天已经刷新过就跳过，失败时保留上一份榜单、稍后重试，不会把页面清空。

## 四、洛天依为什么有两个来源

同一个名字在网易云有两个账号：官方的 `洛天依Official`，以及专门发布同人投稿的
`洛天依`。两个都要取——只取官方会漏掉社区创作，只取同人会看不到官方作品。
页面上每条歌都带来源标签。多个来源按「轮流取」合并，保证两边的歌都能上榜，
而不是被数量多的一边盖掉。

## 五、艺人账号怎么确定

同名艺人太多（`洛天依Official` / `洛天依` / `プロジェクトセカイ`），按名字或数量猜
都会挂错人的作品。所以档案里每个来源都是人工核对后确定的，不做自动匹配。

## 六、注意事项

- 页面只做「跳转入口」，不提供播放、不缓存音频，页面底部已注明版权归属。
- 会员曲目、下架曲目在网易云一侧的可见性变化，会直接反映在代表作列表里。
- 榜单每日自动更新；如果某位声库的代表作长期没有变化，通常是该账号近期没有新投稿。
