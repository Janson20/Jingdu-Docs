# 论坛交流

在论坛发帖和讨论，与社区成员互动。

## 浏览帖子

- 在首页作品广场点击 **帖子** 标签，或访问 `/?type=forum`
- 帖子进入统一无限瀑布流，滚动加载下一页；旧的 `/forum` 入口仍然可用
- 每个帖子显示浏览量、回复数与互动数据

## 发布帖子

1. 登录后，在 `/publish` 选择 **帖子** 标签（也可以直接访问 `/forum/create`）
2. 输入：
   - **标题** — 帖子标题
   - **内容** — 帖子正文
3. 点击「发布」

::: info 发布限制
- 每天最多发布 **10 + 等级** 个帖子（如 Lv.3 用户每日上限 13 个）
- 发布帖子可获得 **10 经验值**，每日最多 10 次
:::

## 分区与标签

- 发帖时需要选择分区：**杂谈、求助、教程、分享、资源**；未选择或参数异常时自动归入 **杂谈**。
- 可以填写最多 **5 个**标签，每个标签不超过 **10 个字符**，用逗号分隔；不填时显示「无标签」。
- 分区与标签会显示在作品流卡片和帖子详情中。点击卡片上的分区或标签，可以只看该分区 / 标签下的内容。
- 编辑帖子时可以同时修改分区与标签。

## 图文帖子

- 发帖时可以选择最多 **9 张**配图，支持 JPG / PNG / WebP，单张不超过 **5 MB**。
- 图片上传时先校验扩展名、大小与文件头，再送**视觉模型 AI 审核**；明确通过后才写入公开存储并分发。
- 审核不通过或无法确认的图片不会发布，页面会提示原因；已发布帖子的配图会显示在首页卡片与帖子详情中。
- 帖子详情页的配图点开即可**在页内放大**（不再跳转图片地址）：多图可左右切换，键盘 ← → 翻页、Esc 关闭，手机上可左右滑动；Ctrl / Cmd + 点击仍按浏览器默认行为在新标签打开原图。
- 编辑帖子时可以勾选删除已有配图，也可以继续添加新图；保留的旧图不会重复审核，新增图片仍会先经过视觉模型审核。配图总数最多 9 张。
- 删除帖子时，帖子、图片记录与已上传的图片文件会一起清理。

::: tip 发布前审核
帖子发布与编辑会先经过发布频率、重复与广告等算法风控，再走 AI 内容审核；配图另走视觉模型审核。通过即刻发布；提示未通过时可修改后重新提交；少数内容会转人工复核，复核通过后自动发布，可在 **我的作品**（`/my/works`）看到「审核中 / 未通过」状态。评论命中广告、联系方式、灌水等风险时也会送 AI 审核。详见 [内容审核与风控](/features/moderation)。
:::

## 帖子详情

点击帖子标题进入详情页，可以看到：

- 帖子完整内容
- 所有回复（支持楼中楼结构）
- 表情自动转换（如 `:)` 会自动变成对应表情）

## 回复帖子

1. 在帖子详情页输入回复内容
2. 可以引用其他楼层进行回复（楼中楼）
3. 点击「发表回复」

::: tip
- 登录后评论可获得 **3 经验值**，每日最多 10 次
- 回复会显示 IP 归属地
- 支持 `:)` 等表情代码自动转换为 emoji
:::

## 管理帖子

### 我的帖子

登录后，通过个人中心或 `/my/works?type=forum` 查看你发布的所有帖子与审核记录。

### 编辑帖子

- 进入帖子详情页，点击 **编辑** 按钮（仅作者可见）
- 修改标题、内容、分区与标签；也可以勾选删除已有配图、选择新图补充
- 点击「保存」后，正文、分区、标签与配图一起生效；新增图片未通过 AI 审核时不会保存

### 删除帖子

- 进入帖子详情页，点击 **删除** 按钮（仅作者可见）

### 删除评论

- 帖子作者和评论者可以删除评论

## 帖子互动

帖子与博客、资源共用同一套互动栏和评论区，支持**点赞、点踩、收藏、转发、评论**。

### 点赞与点踩

- 点赞、点踩互斥；再次点击同一种态度即取消。
- 作者被点赞 +2 净币、被点踩 -1 净币；自赞自踩只记录态度，不结算净币。
- 每个作者每日因被点踩扣除的净币有上限（默认 20 净币）。
- 点赞 / 点踩会计入作者经验与成就，具体上限沿用原有规则。

### 收藏

- 收藏后可随时取消；收藏数按真实记录统计。
- 登录后可在「我的收藏」查看帖子、博客、资源三类内容。

### 转发给好友

- 转发按钮会把内容以站内卡片的形式发给私信好友，卡片展示类型、标题、作者、摘要、封面与真实互动数。
- 不能转发给自己、系统公告，或与当前用户互相拉黑的人。
- 帖子作者每被转发可获得经验奖励（沿用原有规则）。

### 评论

- 评论支持楼中楼回复；帖子作者与评论作者可以删除评论，删除父评论会一并删除回复。
- 评论与博客、资源共用统一审核、IP 属地与经验规则。

### 查看我的互动

- 「我的收藏」：`/my/bookmarks`
- 「我的点赞」：`/my/likes`
- 旧的 `/forum/my-likes`、`/forum/my-bookmarks` 仍然保留。

`GET /api/forum/<post_id>/status` 继续返回当前的 `attitude`（`1` 点赞、`-1` 点踩、`0` 未操作），并新增统一接口 `GET /api/content/forum_post/<post_id>/status`。

详见 [净币系统](/features/coin#互动与净币)。
