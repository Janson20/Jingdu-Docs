# 论坛交流

在论坛发帖和讨论，与社区成员互动。

## 浏览帖子

- 在首页作品广场点击 **帖子** 标签，或访问 `/?type=forum`
- 帖子进入统一无限瀑布流，滚动加载下一页；旧的 `/forum` 入口仍然可用
- 每个帖子显示浏览量、回复数与互动数据

## 发布帖子

1. 登录后，在 `/publish` 选择 **帖子** 标签（也可以直接访问 `/forum/create`）
2. 输入：
   - **标题** — 帖子标题
   - **内容** — 帖子正文
3. 点击「发布」

::: info 发布限制
- 每天最多发布 **10 + 等级** 个帖子（如 Lv.3 用户每日上限 13 个）
- 发布帖子可获得 **10 经验值**，每日最多 10 次
:::

## 分区与标签

- 发帖时需要选择分区：**杂谈、求助、教程、分享、资源**；未选择或参数异常时自动归入 **杂谈**。
- 可以填写最多 **5 个**标签，每个标签不超过 **10 个字符**，用逗号分隔；不填时显示「无标签」。
- 分区与标签会显示在作品流卡片和帖子详情中。点击卡片上的分区或标签，可以只看该分区 / 标签下的内容。
- 编辑帖子时可以同时修改分区与标签。

## 图文帖子

- 发帖时可以选择最多 **9 张**配图，支持 JPG / PNG / WebP，单张不超过 **5 MB**。
- 图片在服务端校验扩展名、大小与文件头后，会先送**视觉模型 AI 审核**；明确通过才写入公开 OSS 桶（`jingdu-proj-public`，经 `cdn.jingdu.org` 分发）。
- 审核不通过或无法确认的图片不会发布，页面会提示原因；已发布帖子的配图会显示在首页卡片与帖子详情中。
- 帖子详情页的配图点开即可**在页内放大**（不再跳转图片地址）：多图可左右切换，键盘 ← → 翻页、Esc 关闭，手机上可左右滑动；Ctrl / Cmd + 点击仍按浏览器默认行为在新标签打开原图。
- 编辑帖子时可以勾选删除已有配图，也可以继续添加新图；保留的旧图不会重复审核，新增图片仍会先经过视觉模型审核。配图总数最多 9 张。
- 删除帖子时，帖子记录、图片记录与 OSS 对象会一起清理。

::: tip 发布前审核
帖子发布与编辑会先经过发布频率、重复与广告等算法风控，再走 AI 内容审核；配图另走视觉模型审核。通过即刻发布；提示未通过时可修改后重新提交；少数内容会转人工复核，复核通过后自动发布，可在 **我的作品**（`/my/works`）看到「审核中 / 未通过」状态。评论命中广告、联系方式、灌水等风险时也会送 AI 审核。详见 [内容审核与风控](/features/moderation)。
:::

## 帖子详情

点击帖子标题进入详情页，可以看到：

- 帖子完整内容
- 所有回复（支持楼中楼结构）
- 表情自动转换（如 `:)` 会自动变成对应表情）

## 回复帖子

1. 在帖子详情页输入回复内容
2. 可以引用其他楼层进行回复（楼中楼）
3. 点击「发表回复」

::: tip
- 登录后评论可获得 **3 经验值**，每日最多 10 次
- 回复会显示 IP 归属地
- 支持 `:)` 等表情代码自动转换为 emoji
:::

## 管理帖子

### 我的帖子

登录后，通过个人中心或 `/my/works?type=forum` 查看你发布的所有帖子与审核记录。

### 编辑帖子

- 进入帖子详情页，点击 **编辑** 按钮（仅作者可见）
- 修改标题、内容、分区与标签；也可以勾选删除已有配图、选择新图补充
- 点击「保存」后，正文、分区、标签与配图一起生效；新增图片未通过 AI 审核时不会保存

### 删除帖子

- 进入帖子详情页，点击 **删除** 按钮（仅作者可见）

### 删除评论

- 帖子作者和评论者可以删除评论

## 帖子互动

在帖子详情页，帖子内容下方有互动按钮栏，你可以：

### 点赞

- 点击 ❤️ **点赞** 按钮为帖子点赞，再次点击取消
- 帖子作者每被点赞可获得 **1 经验值**（每日上限 50 次）
- 登录后在 **我的点赞** 页面可查看你点赞过的所有帖子

### 收藏

- 点击 ⭐ **收藏** 按钮收藏帖子，再次点击取消收藏
- 帖子作者每被收藏可获得 **2 经验值**（每日上限 30 次）
- 登录后在 **我的收藏** 页面可查看你收藏过的所有帖子

### 转发给好友

- 点击 ↗️ **转发** 按钮，选择私信好友即可将帖子摘要转发给对方
- 转发内容包括帖子标题、作者、前 200 字摘要和帖子链接
- 不能转发给已拉黑的用户或自己
- 帖子作者每被转发可获得 **3 经验值**（每日上限 20 次）

### 查看我的互动

在论坛首页或「我的帖子」页面，通过 tab 标签可切换查看：

- **我的帖子** — 你发布的所有帖子
- **我的点赞** — 你点赞过的帖子
- **我的收藏** — 你收藏过的帖子


## 点踩

除点赞、收藏与转发外，论坛帖子支持 **点踩**：

- **点踩**：帖子作者扣除 `1` 净币
- **同一帖子只能点赞或点踩**：再次点击同一种态度即为取消；从点赞改为点踩时会先回退点赞收益再结算点踩
- 取消操作会对称回退，反复切换不会凭空产生净币
- 给自己的帖子点赞或点踩只记录态度，不结算净币
- 每个作者每日因被点踩而扣除的净币有上限（默认 20 净币），达到上限后仍可被点踩并正常计数

帖子详情页的互动栏同时显示点赞数与点踩数，`GET /api/forum/<post_id>/status` 也会返回当前的 `attitude`
（`1` 点赞、`-1` 点踩、`0` 未操作）。

详见 [净币系统](/features/coin#互动与净币)。
