# 工具箱

净读提供可扩展的在线工具集合平台。

## 浏览工具

- 点击导航栏 **工具箱** 进入工具列表页（`/toolkit`）
- 工具按编号排列为卡片，展示图标、名称与简介
- 点击卡片或 **打开工具** 直接进入工具；点 **查看详情** 查看版本、作者与使用说明

## 使用工具

1. 在列表页点击 **打开工具**
2. 工具在独立页面中运行，顶部工具栏可以返回工具箱、在新标签打开或切换全屏
3. 处理较大的文件时尽量保持页面在前台；手机上建议横屏

## 工具框架

工具箱采用 **可扩展框架** 设计，支持动态添加新工具：

- 每个工具以目录形式放在 `data/toolkit/<工具id>/` 下，`about.json` 提供名称与说明，`index.html` 是工具本体
- 工具本体以 **iframe 内嵌** 方式运行在 `/tool/<id>` 页面里，工具自身的内联脚本、样式与本地数据互不干扰
- 支持独立工具说明页面（`/tool-info/<id>`）

### 加载策略说明

工具页面与主站页面使用 **不同的内容安全策略（CSP）**：

- 主站页面保持严格策略，只允许自身与必要的第三方资源
- 工具页面单独放行 `内联脚本`、`data:` / `blob:` 资源、CDN 样式以及工具内部的预览 iframe，
  这样工具才能正常工作；否则浏览器会拦截这些内容并显示「已阻止此内容」的提示
- 工具页面仍然只允许被本站页面嵌套（`frame-ancestors 'self'`），避免被外部站点盗链

::: tip
如果你开发的新工具需要额外的外部域名或特殊能力，请在提交工具时一并说明。
:::
