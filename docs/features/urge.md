# 催更功能

作为读者，你可以对你喜欢的作品进行催更，提醒作者更新。

## 如何催更

1. 读到本书最后一章后，点击 **下一章** 进入 **书末页**
2. 在书籍详情页点击 **催更** 按钮，也会直达书末页的催更位置
3. 在书末页点击「催更本书」即可，按钮上会实时显示本书的累计催更次数

## 催更规则

- 需要登录才能提交催更
- 催更只累计「每本书的催更次数」，不再记录谁在什么时候催更了哪本书
- 为防刷量，催更提交有频率限制（每个 IP 每小时 20 次）

## 查看催更次数

- 书末页的催更按钮上直接显示「已催更 N 次」
- 也可以通过接口查询：`GET /api/urge/book/<book_id>`

> 提示：原来的催更页（`/cg/<book_id>`）和催更历史页（`/urge_history`）已下线，
> 催更统一在书末页完成，不再展示催更明细。
