# 中V史

「中V史」是净读的原创编年栏目：以编年体记录 2010–2026 年中文歌声合成（中V）的作品、人物、公司与引擎，另设三卷专志与全量作品索引。入口在顶部导航「中V史」，地址为 **/history**。

## 全书结构

| 卷次 | 时间范围 | 内容 |
|---|---|---|
| 卷一 | 2010.01–2014.01 | 前史与 VOCALOID CHINA PROJECT 时代 |
| 卷二 | 2014.02–2019.12 | VOCANESE 与后 Vsinger 时代 |
| 卷三 | 2020.01–2026.10 | 引擎混战、AI 浪潮与十周年时代 |
| 专志一 | 2010–2026 | 争议事件志：按甲、乙、丙、丁四类补全 27 起案件的谱系 |
| 专志二 | 2010–2026 | P主传：31 位（组）创作者的纪传体合志，附「赞曰」与收录依据 |
| 专志三 | 2010–2026 | 作品志：3 组系列总条、32 条正条与 36 条附条 |
| 附录 | 2010–2026 | 全量作品索引：9,219 条登记，可检索、可分页 |
| 编例 | 全书通则 | 总凡例与文献主表，含 155 条统一编号文献 |

总览页还提供七个分期的横向时间轴、六条阅读路径，以及确定度标记和来源分级的速查表。

## 怎么读

### 时间轴

正史三卷按时间顺序排列。每个年份有一条粗分隔线，条目左侧是日期栏，右侧依次是：

- **主体**：事件涉及的公司、企划、创作者或作品；
- **事件**：当天发生了什么；
- **后果**：以「→」开头的直接影响；
- **按语**：以「按」标出的解释、评价或存疑，与事实句分开；
- **出处**：正文中的 [n] 是文献编号，点击可跳到编例页的文献主表。

### 目录与进度

桌面端左侧固定显示「全书章节」和「本卷目录」，滚动时自动高亮当前节。移动端顶部有「目录」按钮，打开底部抽屉，可跳章节或回到顶部。页面顶部有一条细进度条，表示正文已读比例。

### 专志一：争议案件

《争议事件志》把每起案件做成一张卡：起因、冲突、升级、处理、结果、后续、谱系分字段排列；标题右侧是当前状态（已闭合、无下文、各执一词等）。文末有谱系总表和五个模式的总结。

### 专志二：传记卡

《P主传》按甲（创世一代）、乙（中坚一代）、丙（附条）、丁（待考）分代，每条一张传记卡：

- 卡头是编号、姓名、副题（如「跨语种第一人」）、层级标签与活跃区间；
- 正文「传」是连续叙事，事实句逐句带 `〔源 n〕` 与确定度标记；
- 条末「赞曰」是评价栏，与事实句严格分开；
- 「收录依据／谱系／互链」按字段列出立条通道、证据与跨志链接。

### 专志三：作品卡

《作品志》先列系列总条，再按投稿时间排正条与附条。每条作品卡给出作品名、投稿日期与平台、层级标签；正文里的「版本记录」单独成行，说明重制、换引擎、重投等版本关系；「互链」指向 P主传、争议事件志与全量索引行。附条（A-01 起）收成带锚点的清单，可被其他卷直接跳转。

### 附录：全量作品索引

《全量作品索引》登记 9,219 条作品，字段定义、四层采集现状与口径红线写在页内「索引编例」中。索引支持：

- 关键词检索（作品名、别名、P主、编号）；
- 按年份、收录层、状态筛选；
- 分页展示，每页 60 条；
- 查号：`/history/works-index?w=W00004` 直接显示该行全部字段，并可前后翻看相邻行。

索引只登记不评级；正条、附条与待考的筛选在《作品志》里完成。

### 跨志互链

正文中的四类记号可以点击跳转，而不是普通括注：

| 记号 | 指向 |
|---|---|
| `〔P主 n〕` | 传记卡 `#p-n` |
| `〔专志三 n〕`／`〔专志三 A-01〕` | 作品条 `#w-n`／附条 `#w-a-01` |
| `〔专志一 A1〕` | 案件卡 `#case-a1` |
| `〔索引 W00004〕` | 全量索引的查号页 |

编例里讲「记号用法」的占位（如「条目编号〔P主 n〕连续不动」）按代码样式显示，不是链接。

## 标记与来源

| 标记 | 含义 |
|---|---|
| ✔ | 有一手材料，或两个以上独立来源互证 |
| 〔待核〕 | 尚未取得一手佐证，仅存条目 |
| 〔歧〕 | 史料互斥，并列存目，不作认定 |
| 〔口径〕 | 判定标准不同，不是史料冲突 |
| 〔推论〕 | 方向可信、强度不可信的解释 |
| 〔争议〕 | 指认与回应并存，本卷不作认定 |

来源分三级：A 级为官方公告、投稿页、工商记录、当事人一手陈述；B 级为年表、通鉴、权威百科与数据库；C 级为新闻聚合、观点专栏、社群讨论，只作线索。未加确定度标记者，视为「据所引文献单独成立」；C 级单源一律〔待核〕。

## 内容维护

《中V编年》是只读的编辑内容，由净读编辑团队整理，普通用户不能直接修改正文。

- **书目结构**：全书分为三卷正史、三卷专志、索引编例与总凡例，目录、分期、标记定义与原创声明统一维护；
- **正文格式**：正史按编年体、专志按纪传体撰写；一级标题为卷、二级标题分节，三级标题在正史里表示阶段、在争议志里表示案件、在 P主传与作品志里表示传记与作品；
- **全量索引**：作品索引单独维护，更新后页面立即展示最新一期；
- **纠错与补充**：发现错漏，或想补充未收录的作品，可通过[反馈中心](https://jingdu.productbridge.io)提供来源线索。

新增一卷或调整分期时，目录、时间轴与跨志互链会一起更新；文献编号全书唯一，改动会同步到所有出现处。索引字段口径与列名见《全量作品索引·编例》。

## 常见问题

**为什么同一天有两个日期？**

可能是投稿日与播出日、录制日与播出日，或两个来源的精度不同。条目内会标〔歧〕或〔口径〕，并并列写出两个日期，不强行合并。

**为什么引用要跳到编例页？**

全书使用统一文献编号，同一文献在全书只给一个号；各卷卷末只列本卷所引条目，点击编号最终都回到编例页的文献主表。

**为什么索引里的 W 号和作品志的编号不一样？**

W 号是《全量作品索引》的行号，按投稿日期排序、只登记不评级；作品志的 1–32 是正条编号，S1–S3 是系列总条，A-01 起是附条。两套编号靠「互链」字段对应。

**可以转载吗？**

可以引用观点与结论，但需注明「来源：净读 · 中V史」并保留原文链接；全文转载、摘编成册或商业使用需取得本站书面许可。
