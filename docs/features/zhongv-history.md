# 中V史

「中V史」是净读的原创编年栏目：以编年体记录 2010–2026 年中文歌声合成（中V）的作品、人物、公司与引擎。入口在顶部导航「中V史」，地址为 **/history**。

## 全书结构

| 卷次 | 时间范围 | 内容 |
|---|---|---|
| 卷一 | 2010.01–2014.01 | 前史与 VOCALOID CHINA PROJECT 时代 |
| 卷二 | 2014.02–2019.12 | VOCANESE 与后 Vsinger 时代 |
| 卷三 | 2020.01–2026.10 | 引擎混战、AI 浪潮与十周年时代 |
| 专志一 | 2010–2026 | 争议事件志：按甲、乙、丙、丁四类补全案件谱系 |
| 编例 | 全书通则 | 总凡例与文献主表，含 94 条统一编号文献 |

总览页还提供七个分期的横向时间轴、四条阅读路径，以及确定度标记和来源分级的速查表。

## 怎么读

### 时间轴

正史三卷按时间顺序排列。每个年份有一条粗分隔线，条目左侧是日期栏，右侧依次是：

- **主体**：事件涉及的公司、企划、创作者或作品；
- **事件**：当天发生了什么；
- **后果**：以「→」开头的直接影响；
- **按语**：以「按」标出的解释、评价或存疑，与事实句分开；
- **出处**：正文中的 [n] 是文献编号，点击可跳到编例页的文献主表。

### 目录与进度

桌面端左侧固定显示「全书章节」和「本卷目录」，滚动时自动高亮当前节。移动端顶部有「目录」按钮，打开底部抽屉，可跳章节或回到顶部。页面顶部有一条细进度条，表示正文已读比例。

### 专志案件

《争议事件志》把每起案件做成一张卡：起因、冲突、升级、处理、结果、后续、谱系分字段排列；标题右侧是当前状态（已闭合、无下文、各执一词等）。文末有谱系总表和五个模式的总结。

### 编例与文献

编例页解释全书统一编号、分期断点、确定度标记、来源分级、计数口径、主体沿革与术语。卷末的「本卷参考文献」默认折叠，展开后可按编号查看本卷所引条目；所有编号最终都指回编例页的文献主表。

## 标记与来源

| 标记 | 含义 |
|---|---|
| ✔ | 有一手材料，或两个以上独立来源互证 |
| 〔待核〕 | 尚未取得一手佐证，仅存条目 |
| 〔歧〕 | 史料互斥，并列存目，不作认定 |
| 〔口径〕 | 判定标准不同，不是史料冲突 |
| 〔推论〕 | 方向可信、强度不可信的解释 |
| 〔争议〕 | 指认与回应并存，本卷不作认定 |

来源分三级：A 级为官方公告、投稿页、工商记录、当事人一手陈述；B 级为年表、通鉴、权威百科与数据库；C 级为新闻聚合、观点专栏、社群讨论，只作线索。未加确定度标记者，视为「据所引文献单独成立」；C 级单源一律〔待核〕。

## 内容维护

正文是只读的编辑内容，随代码入库：

- **content/history/index.json**：书目清单、分期、标记定义、原创声明；
- **content/history/*.md**：五份正文，按编年体 Markdown 维护；
- **vocaloid_history.py**：装载、缓存、文献索引与总览统计；
- **history_render.py**：行内格式、表格、条目、文献表；
- **history_chapter.py**：章节装配、目录、年份分隔；
- **routes/vocaloid_history.py**：/history 与 /history/&lt;slug&gt; 两个路由。

新增一卷时，把 Markdown 放进 content/history/，在 index.json 的 chapters 里补一条（slug、file、label、title、period、summary、kind、accent、order），路由与目录会自动接上。正文第一行用一级标题，二级标题分节，三级标题在正史里表示阶段、在专志里表示案件。

## 常见问题

**为什么同一天有两个日期？**

可能是投稿日与播出日、录制日与播出日，或两个来源的精度不同。条目内会标〔歧〕或〔口径〕，并并列写出两个日期，不强行合并。

**为什么引用要跳到编例页？**

全书使用统一文献编号，同一文献在全书只给一个号；各卷卷末只列本卷所引条目，点击编号最终都回到编例页的文献主表。

**可以转载吗？**

可以引用观点与结论，但需注明「来源：净读 · 中V史」并保留原文链接；全文转载、摘编成册或商业使用需取得本站书面许可。
