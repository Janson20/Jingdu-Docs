# 界面上的说明与提示

净读的界面里，"看不懂就把鼠标停一下"的地方分三类，另外还有一类是"点完之后告诉我结果"，各有各的用法。

## 1. 圈里问号（?）：需要解释的地方

表单字段、AI 参数、计费项目、危险操作旁边会有一个**圈里问号**的小图标：

> 每日可领积分 (?)

把鼠标停在它上面，就会弹出说明气泡。例如：

- **表单怎么填** —— 字数上限、允许的格式、注册后能不能改
- **AI 参数怎么选** —— 各个模式的差别、上下文与轮数上限、什么时候会翻倍计费
- **要花多少积分** —— 哪些操作会扣分、兑换码和套餐的有效期
- **点下去会怎样** —— "删除后不可恢复""解绑后收不到验证码"这类后果
- **为什么点不动** —— 等级不够、需要先绑定邮箱

**不用鼠标也能看**：用 `Tab` 键把焦点移到问号圈上，说明同样会显示；按 `Esc` 可以立刻收起。

## 2. 图标按钮：浏览器自带的小提示

纯图标按钮（回到顶部 `↑`、阅读设置 `⚙`、关闭 `✕`、重命名 `✎` 等）鼠标停上去，会出现**浏览器原生的浅黄色小提示**，写着这个按钮是干什么的。这是浏览器自带的样式，不跟随网站配色。

## 3. 被省略号截断的文字

列表和表格里被 `…` 截断的标题、用户标识等，鼠标停上去也会用浏览器原生提示显示完整内容。

## 4. 操作结果：底部弹出的提示条

保存章节、删除作品、提交评论、领取任务奖励、兑换兑换码、复制链接……这类"点一下、马上有个结果"的操作，结果统一从**屏幕底部**弹出一条提示：

| 颜色 | 含义 | 例子 |
|------|------|------|
| 绿色 · 对勾 | 操作成功 | 章节已保存 |
| 黄色 · 感叹号 | 还差一步，需要你补充或确认 | 请先填写邮箱地址 |
| 红色 · 感叹号 | 操作失败 | 网络异常，请稍后重试 |
| 蓝色 · 圆圈 i | 中性信息 | 已复制链接 |

几条使用上的约定：

- 提示大约 3 秒后自动消失；**鼠标停在提示上会暂停计时**，看长文案不会被打断；点一下可以提前关掉。
- 同一句话重复出现不会叠成一堆，只会把计时重新开始。
- 极少数需要你自己确认过才消失的提示会带一个关闭按钮，不会自动跑掉。
- 手机上提示会自动浮在底部导航栏**上方**，不会盖住"首页 / 小说 / 发布 / 消息 / 我的"。
- 换页带过来的提示（例如退出登录后的"你已成功退出登录"）同样从底部弹出，不再在页头插一条横幅，也不会再出现浏览器自带的弹窗（那种弹窗会把整页锁住、样式也不跟网站走）。

以前这三件事在不同页面是三种做法：有的底部弹一行小字、有的在页头插一条横幅、有的直接用浏览器原生弹窗。现在统一成上面这一种。

## 为什么不是"到处都有气泡"

我们一开始试过给所有按钮、链接、徽章都挂上说明气泡，结果页面上到处都在弹框，反而没人看。所以现在只保留**真正需要解释**的地方用问号圈，其余交给浏览器自带的提示，页面清爽很多。

## 手机上怎么看

手机上"把鼠标停在图标上"这一套不管用（滑动手势和长按菜单会冲突），所以改成**用手指点一下问号圈**，说明就会弹出来；点到别处会自动收起。图标按钮在手机端都配有对应的文字标签，不影响使用。

## 气泡挡住了内容怎么办

气泡不会挡住点击 —— 它不接收鼠标事件，鼠标可以直接"穿过"它。如果它正好盖住你想看的地方，把鼠标移开，或者滚动一下页面，它就会自动消失。
