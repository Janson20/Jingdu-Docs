# 界面上的说明与提示

净读的界面里，"看不懂就把鼠标停一下"的地方分三类，各有各的用法。

## 1. 圈里问号（?）：需要解释的地方

表单字段、AI 参数、计费项目、危险操作旁边会有一个**圈里问号**的小图标：

> 每日可领积分 (?)

把鼠标停在它上面，就会弹出说明气泡。例如：

- **表单怎么填** —— 字数上限、允许的格式、注册后能不能改
- **AI 参数怎么选** —— 各个模式的差别、上下文与轮数上限、什么时候会翻倍计费
- **要花多少积分** —— 哪些操作会扣分、兑换码和套餐的有效期
- **点下去会怎样** —— "删除后不可恢复""解绑后收不到验证码"这类后果
- **为什么点不动** —— 等级不够、需要先绑定邮箱

**不用鼠标也能看**：用 `Tab` 键把焦点移到问号圈上，说明同样会显示；按 `Esc` 可以立刻收起。

## 2. 图标按钮：浏览器自带的小提示

纯图标按钮（回到顶部 `↑`、阅读设置 `⚙`、关闭 `✕`、重命名 `✎` 等）鼠标停上去，会出现**浏览器原生的浅黄色小提示**，写着这个按钮是干什么的。这是浏览器自带的样式，不跟随网站配色。

## 3. 被省略号截断的文字

列表和表格里被 `…` 截断的标题、用户标识等，鼠标停上去也会用浏览器原生提示显示完整内容。

## 为什么不是"到处都有气泡"

我们一开始试过给所有按钮、链接、徽章都挂上说明气泡，结果页面上到处都在弹框，反而没人看。所以现在只保留**真正需要解释**的地方用问号圈，其余交给浏览器自带的提示，页面清爽很多。

## 手机上怎么看

手机上"把鼠标停在图标上"这一套不管用（滑动手势和长按菜单会冲突），所以改成**用手指点一下问号圈**，说明就会弹出来；点到别处会自动收起。图标按钮在手机端都配有对应的文字标签，不影响使用。

## 气泡挡住了内容怎么办

气泡不会挡住点击 —— 它不接收鼠标事件，鼠标可以直接"穿过"它。如果它正好盖住你想看的地方，把鼠标移开，或者滚动一下页面，它就会自动消失。

::: details 维护者备注：新增提示的写法

**只有"需要解释"的地方才用问号圈**，写法是在要解释的文字旁边放一个空 span：

```html
<label for="username">用户名<span class="help-tip" data-tip="账号唯一标识，注册后不可修改"></span></label>
<input type="text" id="username" name="username">

<!-- 两行写法：&#10; 会原样换行 -->
<h3>AI 订阅<span class="help-tip" data-tip="每日可领一次&#10;次日 0 点重置"></span></h3>
```

`static/js/script.js` 会自动给 `.help-tip` 补上 `role` / `tabindex` / `aria-label`，**不需要手写**。
可选属性：`data-tip-pos="top|bottom|left|right"`（优先方位）、`data-tip-delay="600"`（延迟毫秒）。

**不要**用问号圈的地方：

| 场景 | 正确做法 |
|------|---------|
| 纯图标按钮 | 原生 `title`，例如 `<button title="回到顶部">↑</button>` |
| 链接跳到哪 | 不加任何提示 |
| 状态徽章、时间、UUID、计数 | 不加任何提示 |
| 被省略号截断的文本 | 原生 `title`，鼠标停上去看全文 |

四条容易踩的约定：

1. **`data-tip` 只能出现在 `.help-tip` 上** —— `tests/unit/test_tooltip.py` 会逐模板检查。
2. **不要同时写 `title` 和 `data-tip`** —— 原生提示和自定义气泡会一起弹，屏幕上是两个框。
3. **问号圈不要放进 `<a>` 或 `<button>` 里**：
   - 链接整条可点，圈放在里面会让键盘焦点落进链接内部；
   - 按钮里的圈点下去会**真的触发按钮动作**（手机上想读一下「清空对话」的说明，结果对话真被清空了），而且 HTML 规范也不允许按钮包含可聚焦元素。

   按钮旁的圈请用 `.tip-with` 包一层，让圈成为按钮的**兄弟节点**：

   ```html
   <span class="tip-with">
       <button type="button" class="btn btn-danger">清空对话</button>
       <span class="help-tip" data-tip="清空当前会话的全部消息&#10;清空后无法恢复"></span>
   </span>
   ```

4. 文案是**纯文本**，写在 `data-tip` 里的 HTML 标签会被原样显示出来。
:::
