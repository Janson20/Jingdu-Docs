# 认识净读

**净读** (JingDu) 是一个免费、无广告的综合性阅读社区网站。

## 主要功能

| 功能 | 说明 |
|------|------|
| 书籍阅读 | 浏览和阅读社区书籍，支持标签浏览与关键词搜索 |
| 作品广场 | 类似 V 次元的三栏信息流，浏览工程、帖子、博客与资源，页内标签切换类别 |
| 图文帖子与博客 | 帖子、博客支持分区与标签，最多 9 张配图可编辑增删；图片经 AI 审核后写入公开 OSS 桶 |
| 统一发布 | 在一个页面用标签切换四类作品的发布表单 |
| 我的作品 | 在个人中心集中管理已发布作品与审核记录 |
| 写作发布 | 创建和管理自己的书籍作品，支持多标签 |
| 博客系统 | 使用 Markdown 发布博客文章 |
| 论坛交流 | 发帖讨论，楼中楼回复互动 |
| 资源分享 | 分享软件资源，支持标签与版本管理 |
| AI 聊天 | 集成多个 AI 模型，积分制使用 |
| 等级系统 | 10 级等级体系，每日任务获取经验 |
| 聊天室 | 公共实时聊天室 |
| 工具箱 | 可扩展的在线工具集合 |

## 网站导航

登录后，页面顶部导航栏提供以下入口：

- **首页 / 作品广场** — 工程、帖子、博客、资源的三栏信息流；页内标签切换类别
- **发布** — 统一发布页，页内标签切换工程 / 帖子 / 博客 / 资源（需登录）
- **小说** — 图书库入口，支持关键词搜索与标签筛选
- **工具箱** — 在线工具集合
- **AI 聊天** — AI 智能对话（需登录）

登录后，个人中心（点击右上角用户名）里有「我的作品」入口，集中管理四类作品；别人主页上的「TA的作品」会打开该作者的公开作品流。

导航栏右侧功能区：

- **私信** — 消息图标，显示未读消息数（含系统公告未读）
- **等级徽章** — 显示当前等级名称和颜色
- **AI 积分余额** — 显示剩余积分
- **用户名下拉菜单** — 我的作品、发布作品、个人主页、编辑资料、设置、等级中心、AI充值、登出

### 其他重要页面入口

- **等级中心** (`/exp`) — 查看经验值和每日任务完成状态
- **AI 充值** (`/ai_recharge`) — 每日签到、兑换码充值、每日任务奖励
- **AI 成本仪表盘** (`/ai_chat/dash`) — 查看 AI 使用成本分析
- **系统公告** (`/message/0`) — 查看管理员发布的站内公告

## 深色/浅色主题

网站支持深色和浅色主题切换，点击页面右上角的主题切换按钮即可切换。默认跟随你的系统设置，手动切换后会记住你的选择，下次访问依然生效。

全站采用统一的配色（主色 `#66CCFF`），浅色与深色两套主题的对比度都经过校验，长时间阅读不刺眼。

## 界面上的说明与提示

遇到看不懂的字段或参数，看看旁边有没有**圈里问号（?）**的小图标 —— 鼠标停上去（或按 `Tab` 聚焦）就会弹出说明，讲清楚怎么填、要花多少积分、点下去会有什么后果。纯图标按钮则用浏览器自带的小提示。详见 [界面上的说明与提示](/guide/interface)。
