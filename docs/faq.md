# 常见问题

## 账号相关

### 忘记密码怎么办？

目前暂不支持通过邮箱找回密码。如果你忘记了密码，请联系网站管理员。

### 注册时收不到验证码？

- 检查邮箱地址是否正确
- 检查邮箱的垃圾邮件文件夹
- 确认距离上次发送已超过 60 秒
- 如果仍然无法收到，可能是邮箱服务商的问题

### 用户名有什么限制？

用户名不能包含敏感词，长度有一定限制。建议使用字母、数字和下划线组合。

## 书籍相关

### 如何发布书籍？

详见 [写作发布](/features/writing)。

### 如何上传封面图片？

在新建书籍时，支持上传封面图片（JPG / PNG / GIF / WebP）。如果不上传，系统会按书名与作者自动生成一张站点主题色的矢量占位封面，不再使用统一的默认图片。

### 占位封面可以换成自己的图片吗？

可以。占位封面只是「没有上传封面」时的展示方案；上传封面后就会一直使用你上传的图片。目前不支持在创建之后替换封面，如需更换请重新发布书籍或联系管理员。

### 可以发布已经进入公共领域的经典作品吗？

可以，但要按「转载」发布：在新建书籍页勾选 **转载公共版权作品** 并填写 **原作者**（必填）。这类书籍会在详情页同时显示转载者与原作者，列表带「转载」徽标；同时有两条限制 —— **不能开启 VIP 收费章节**，也**不参与净币收益**（正文不是你的创作）。请确认作品确实已进入公共领域（作者逝世满 50 年，或权利人明确允许自由传播），虚假声明会按版权政策处理。详见 [写作发布](/features/writing)。

### 转载标记填错了怎么办？

转载标记与原作者创建后不能由作者自行修改，请联系管理员在管理后台编辑（管理员可修改书籍的书名、作者、封面、简介、标签与转载信息）。

### 可以用 EPUB 文件整本导入吗？

可以，但仅限**转载公共版权作品**：在「新建书籍」页勾选「转载公共版权作品」，填好原作者后选择 `.epub` 文件，系统会自动解析出书名、原作者与全部章节，创建时一次性写入（最多 500 章、单个文件最大 20 MB）。只会导入正文文字，书里的图片与封面不会导入，未上传封面时使用自动生成的主题色占位封面。原创作品请逐章发布，不支持整本导入。

### 书籍内容支持什么格式？

书籍章节目前以纯文本形式存储和展示。

## AI 聊天相关

### 积分用完了怎么办？

- 每日签到可以获得 20 积分
- 使用兑换码充值积分

### 支持哪些 AI 模型？

目前支持以下模型：

- DeepSeek-V4.1-Flash（通用对话 + 图像理解，模型名：deepseek-flash）
- DeepSeek V4 Pro（深度推理，模型名：deepseek-v4-pro）
- Qwen3.7 Plus（千问增强版）
- Qwen3.6 Flash（千问快速版）
- Qwen3.5 Flash（千问轻量版）
- Qwen3.7 Max（千问旗舰版）

> 旧版模型名称（deepseek-chat、deepseek-reasoner、deepseek-v4-flash、deepseek-v4-flash-vision-exp）仍可兼容使用，系统会自动映射到对应的当前模型。

### AI 聊天记录会保存吗？

聊天记录保存在你的浏览器本地，不会上传到服务器。清除浏览器数据会导致聊天记录丢失。

### 什么是 FIM 补全模式？

FIM（Fill In the Middle）补全模式是 DeepSeek 模型的一项功能，你可以提供内容的开头和结尾，AI 会自动补全中间的部分。适用于续写、代码补全等场景。

### FIM 补全怎么收费？

FIM 补全采用与普通聊天相同的 **基于 token 的阶梯计费**，根据实际输入和输出 token 数量计算积分。开头和结尾内容总长度不超过 1000 字符。仅支持 DeepSeek 系列模型。

### AI 聊天消耗多少积分？

积分消耗取决于实际的 token 用量和所选模型，最低 1 积分。用量越大，后续 token 的兑换率越高。详见 [积分系统说明](/features/ai-chat#积分系统)。

> **大额调用价格说明**：第三阶梯（>10 万 token）的兑换率最高，大额调用更划算。具体兑换率会随上游算力价格波动不定期调整，请以 [AI 聊天页](/features/ai-chat#积分系统) 或 [充值页面](/ai_chat/recharge) 的费率表为准。

### 联网搜索怎么收费？

在 AI 聊天左侧打开 **联网搜索** 后，每条消息最多搜索 2 次、抓取 10 个网页。每次**成功**的搜索或抓取额外收取 **1 积分**，与 token 费用合并扣除；搜索无结果、网页无正文、调用失败或命中缓存不收费。详见 [联网搜索说明](/features/ai-chat#联网搜索)。

### AI 聊天支持数学公式吗？

是的！AI 聊天支持渲染 LaTeX 数学公式。在对话中，AI 返回的数学表达式会自动渲染为美观的公式。支持的语法包括：

- **行内公式**：`$...$` 或 `\(...\)`
- **块级公式**：`$$...$$` 或 `\[...\]`

例如：`$\frac{a}{b}$` 会渲染为行内分数，`$$\int_0^1 x^2 dx$$` 会渲染为独立的积分公式。

### 如何快速升级？

## 公告相关

### 公告附赠的积分有效期是多久？

管理员在发布公告时可以自定义积分有效期，范围为1-365天，默认30天。过期后用户将无法领取该积分。有效期的起始时间为公告发布时间。

### 如何领取公告附赠的积分？

在公告详情页面，如果公告附带了积分奖励且未过期，会显示"领取"按钮。点击即可领取积分到你的账户。每个公告的积分只能领取一次。

## API 相关

### 如何通过 API 获取自己的用户信息？

调用 `GET /api/user/info` 接口，携带登录时获取的 Token 即可。支持两种方式传递 Token：

- **Authorization 请求头**：`Authorization: Bearer <token>`（推荐）
- **查询参数**：`?token=<token>`

返回信息包括：IP 地址、用户名、UUID、用户简介、等级和 AI 积分余额。
